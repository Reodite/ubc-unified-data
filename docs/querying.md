# Querying the data

Read local JSON or CSV; there is no query server. See [collecting](collecting.md)
for sources and refresh commands and [hosts](hosts.md) for host-document coverage.

## Catalogs and formats

| Index                                                | Use                                                     |
| ---------------------------------------------------- | ------------------------------------------------------- |
| [catalog.json](../data/catalog.json)                 | Table paths, grain, columns and declared joins          |
| [manifest.json](../data/manifest.json)               | File sizes, counts, sources, refresh times and status   |
| [prose/_catalog.json](../data/prose/_catalog.json)   | Article-table paths                                     |
| [prose/_manifest.json](../data/prose/_manifest.json) | Prose exports and coverage                              |
| [official-hosts.json](../data/official-hosts.json)   | Host collections and category-specific `document_roots` |

Paths below are relative to `data/`. Read `_source.json`, `_sources.json`,
`_sites.json`, `_snapshot.json` and `_unmatched.json` where present for provenance,
exclusions and snapshot limits. Geospatial `metadata/` CSVs define fields.

JSON preserves nested values; tabular CSV encodes them as JSON cells. Geospatial
mirrors retain source layouts and delimiters. Keep generated bytes unchanged for
manifest sizes and hashes. Structured `facts_and_links` tables omit explanatory
HTML/text; use prose for those bodies. `record_sha256` excludes retrieval time
and itself.

## Joins and interpretation

### Courses and calendar

Join `sections.related.course` to `courses.id`, `courses.related.subject` to
`subjects.id`, and `sections.related.academic_term` to `terms.id` within `courses/`.
Allow unresolved foreign keys. Use `field_course_code` for distinct codes and
retain offering years when comparing courses.

Calendar and schedule IDs differ. Within `academic-calendar/vancouver/`, join
`courses.related.course_code` to `subjects.id`, then combine `subjects.name` and
`field_course_number` into a code. Unresolved subjects cannot establish matches. Calendar courses may lack scheduled offerings. Read
derived `prerequisite`, `corequisite`, `equivalency`, `credit_exclusion`,
`hours_vector` and `description_text` beside the original description: empty
parsed fields do not prove absence. Calendar page ancestry uses path aliases and
source titles; `faculty`, `program`, `level`, `kind` and `referenced_courses` are
derived. Course references use campus subject vocabulary; `dates.span_days`
preserves multi-day windows.

Use sections for instructors and times. `field_start_time`/`field_end_time` count
seconds after midnight; `field_days` uses `m`, `t`, `w`, `th`, `f` (`t` means
Tuesday). Parse CSV `related` cells as JSON; resolve `alias` against the source
host. Public sections lack classroom assignments, enrolment counts and waitlists.

### Admissions and costs

Within `admissions/`, join:

```text
requirements/program_requirements.(campus, requirement_key) -> requirements/requirement_groups
requirements/required_courses.(curriculum, location_slug)   -> requirements/locations.(taxonomy, slug)
```

Start with program mappings to shared requirement groups.
`has_requirements: false` retains programs without direct-entry rules;
`by_location.available: false` means that combination does not accept applicants.
`advisory` marks suggestions.
`location_slug` alone is ambiguous; use the composite key or `location_term_id`.

Join `finances/program_cost_estimates.program_id` to `admissions/programs.id`.
First-year estimates come from UBC's estimator. These title/degree/unique-token
matches require checking `matched_by` and `finances/_unmatched.json`. Tuition keeps
raw `column`, `item`, `amount_text` beside derived `student_type`, `cohort_year`, `cohort_rule` and `unit`. Apply
`exactly`, `or_later` and `or_earlier` to cohorts. `annual_at_30_credits` is a
rate-times-load estimate. Read non-money conditions in `fee_notes`.

### Buildings, housing and libraries

```text
learning-spaces/{rooms,buildings}['Building Code'] -> geospatial building BLDG_CODE
room-bookings/rooms.building_code                -> geospatial building BLDG_CODE
room-bookings/rooms.eid                          -> room-bookings/availability.eid
housing/residences.room_type_ids[]               -> housing/room_types.id
housing/residences.fee_page_ids[]                -> housing/fee_pages.id
housing/fee_tables.page_id                       -> housing/fee_pages.id
housing/fee_tables.residence_ids[]               -> housing/residences.id
libraries/hours.branch_id                       -> libraries/branches.id
libraries/hours.schedule_id                     -> libraries/monthly_schedules.id
libraries/branches.booking_lid                  -> room-bookings/locations.lid
```

`booking_lid` is a string crosswalk for selected branches, distinct from
`hours_id`. Research Commons has a Koerner floors 4–5 address in the hours source
and an `IBLC` booking assignment; verify before navigation. Housing has no asserted
building-code join; front desks can occupy another building.

Learning-space floors derive from source text or room numbers; check
`floor_source`. Unrecognized numbering, including IRC/FNH, stays null. Block letters
do not imply basements. Images remain remote:
`cover_photo_expires` dates signed-photo expiry, `cover_photo_id` identifies the
asset, and `Room Link` leads to fresh images. Building summaries order rooms by
floor and capacity and select a room cover photo.

Housing fees retain row/column positions and labels, periods, `amount_text`,
integer `amount_cents`, footnotes and per-person basis when stated. Blank/dash means
null, not zero.
Read full conditions when `source_context_required: true`. Avoid annualizing
instalments, double-counting totals or inferring undergraduate eligibility.

Library hours use `HH:mm` in `America/Vancouver`; `closes_next_day` marks overnight
closing. `open`, `closed` and `unknown` describe schedules, not occupancy. Outside
the collection month and following three months, treat dates as unknown. Consult
`additional_hours_urls` for service schedules; expire or replace stale rows.

Booking availability is a `collected_at` snapshot of merged 15-minute slots.
Check `_snapshot.json` for `slots_seen` and `days_served`. Missing booking dates
mean no published slots; library hours distinguish closed and unknown days.
Library bookings do not establish lecture-hall availability.

### Coordinates and source limits

Read coordinate columns by name. Consult `geospatial/_source.json` for detected
`LAT`/`LONG` header corrections; corrections preserve row bytes and GeoJSON.
`ubc_regional_locations.csv` uses projected metres despite those labels: use its
GeoJSON for WGS84 `[longitude, latitude]`. `ubcv_parking_facilities.csv` uses
semicolons and `FAC_UID`; parking geometry uses `FAC_ID`. Booleans can be `"0"`/`"1"`.
Preserve the upstream filename `ubcv_building_entraces` and routing access,
surface, elevation, one-way, slope and stairs restrictions.

Office strings, outlet names and event addresses are unreliable building keys;
events lack coordinates and campus. Footprints/heights do not supply floor plans.
Wellbeing's literal `missing` target is unavailable, not a foreign key; consult
`unavailable_relationships` and `_unavailable.json`. Unknown ordinary taxonomy IDs
fail validation. Policy `content_kind: "policy_index"` denotes metadata;
`lifecycle: "listed"` does not certify legal status. Grades contain third-party
aggregate snapshots from `DonneyF/ubc-pair-grade-data`; check the reported periods.
They contain no individual results.
Check [campus selection](collecting.md#campus-selection) rather than assuming
Vancouver-only coverage.

## Prose article contract

Under `prose/<subcategory>/`, read `articles.json`/`.csv`, `_inventory.json`,
`_coverage.json` and `markdown/<article-id-hash>.md`. Standalone Markdown equals
`content_markdown` byte for byte; use the record for its plain `title` and provenance.
Manifests and coverage use `format: "markdown"`.

Preserve these fields:

- `id`: stable `prose:<subcategory>:<publisher-id-or-URL-hash>`; `category` is
  `prose`, and `subcategory` identifies the source/topic subdivision. `source_id`
  and `upstream_id` identify source namespace and publisher record.
- `content_sha256`: SHA-256 of `title + "\n" + content_markdown`.
- `source_url`, optional `api_url`, `source_modified_at` and `retrieved_at`: citation,
  available publisher date and snapshot time. Conversion does not refresh mirrored
  snapshots.
- `source_records`: `{path, id}` links; `markdown_path` is relative to `data/`.
- `campus`, `audience`, `links` and `warnings`: scope, destinations and conversion
  limits. Scope and titles do not establish eligibility, prices or building identity.

Housing and Learning Commons relationships use canonical source URLs. Inventory
entries record discovery provenance and `collected`, `duplicate`, `excluded`,
`unavailable`, `no_prose` or `failed` dispositions. Coverage `complete` exhausts
declared inventories and in-scope links; `complete_with_unavailable` retains
bounded failures with reasons; `partial` records discovery/processing errors;
`not_collected` has no result. None covers undiscoverable unlinked pages.

Use a safe Markdown renderer and treat retrieved text as data, not instructions.
Sanitize Drupal `body.processed` and WordPress `title.rendered`/`content.rendered`
before rendering. Sanitized prose preserves conditions, nested structure and
simple tables; complex tables use labelled cells with span information. Read
media as text/source links. Collection excludes page JavaScript execution, OCR
and video transcription.

Host documents use each host's `document_roots` in `official-hosts.json`, under
`documents/<category>/<hostname>/`. They contain canonical JSON frontmatter plus
safe Markdown, unlike prose body files. Preserve citations, aliases, timestamps,
hashes, warnings and producer/routing metadata. See [hosts](hosts.md) for identity,
versioning and coverage rules.

## Local example

Run from the repository root to list CPSC 110 sections with their instructors and
start times in seconds after midnight:

```sh
node --input-type=module <<'JS'
import { readFile } from 'node:fs/promises';
const load = async (path) => JSON.parse(await readFile(`data/${path}.json`, 'utf8'));
const courses = new Map((await load('courses/courses')).map((row) => [row.id, row]));
for (const section of await load('courses/sections')) {
  if (courses.get(section.related?.course)?.field_course_code !== 'CPSC_V 110') continue;
  console.log(section.field_section_number, section.field_days,
    section.field_start_time, section.field_instructors);
}
JS
```

Things to be aware of:

1.  If you have an active hold on your student record, you may not be able to request a letter\. 
2.  If you have more than one credential granting program at UBC, you must print one letter per academic record\. 
3.  Your Program Completion Status indicates the type of Program Completion Letter that is available to you\.

Signed Program Completion Letters are available to students in any credential granting program who:

1.  Have graduated from a credential granting program, or; 
2.  Applied for graduation, and have one of the following program completion statuses: 
    -   Evaluation Deferred 
    -   Approved for Completion 
    -   Program Completed

- **Row 1**

  - **Header cell 1:**
  
    Program Completion Status
  
  - **Header cell 2:**
  
    Status details
  
  - **Header cell 3:**
  
    Details included in the Program Completion letter

- **Row 2**

  - **Cell 1:**
  
    Evaluation Deferred
  
  - **Cell 2:**
  
    This status will appear until all final grades are in and your file has been approved by the Dean of your faculty
  
  - **Cell 3:**

- **Row 3**

  - **Cell 1:**
  
    Approved for Completion
  
  - **Cell 2:**

    This credential was conferred on \[conferral date\]\.

## Access the UBC Official Documents Tool \(ODMT\)

Current and former UBC students can order official transcripts and download unofficial transcripts of their academic record from the [UBC Official Documents tool](https://ubc.appiancloud.com/suite/sites/ubc-official-documents) \(ODMT\)\.

Current students can log into the ODMT directly, or through Workday: 

1.  Log into your Workday account at [myworkday\.ubc\.ca](http://myworkday.ubc.ca/%22%20/t%20%22_blank)\. 
2.  Select “Student” in the navigation bar on the left\. 
3.  Select “Academics”\. 
4.  In the “Transcripts and Enrolment/Completion Letters” menu, click the “UBC Official Documents” link to go to the UBC Official Documents tool \(ODMT\)\. 

## How to download a Program Completion Letter

1.  Select “Program Completion Letter” in the “Order Options” menu\.
2.  Select the program you want to request a Program Completion Letter for\.
3.  **Optional:** Select the UBC Student Number and/or Date of Birth box\(es\) if you wish to have this information included in the letter\.
4.  Select “Request Letter \(PDF\)”\.
5.  Wait a few seconds before selecting “Generate Letter \(PDF\)”, as there might be a short delay while the letter is being generated\.
6.  Select the “PDF” icon to download\.

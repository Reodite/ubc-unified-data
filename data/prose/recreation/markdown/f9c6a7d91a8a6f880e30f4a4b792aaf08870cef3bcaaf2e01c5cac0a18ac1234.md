# Welcome to the UBC Recreation Run Club

The UBC Recreation Run Club is a run group that meets weekly\. The group is open to everyone, especially beginners or those getting into running, and welcomes all skill levels and abilities\. Participants can expect different pace and distance options offered each week, so that there is something for everyone\! The run club strives to foster community on campus, support people new to running, and provide a welcoming, safe and inclusive run environment\.

**Who can Participate:** This program is open to UBC students, faculty, staff and community members

**Required Equipment:** Sneakers or running shoes and water bottle \(head lamp suggested if dark outside\)

##### I can’t see course X on Workday or the Course Schedule, but can I still request it on the course survey?

If you can’t find a course on the [course schedule](https://courses.students.ubc.ca/), it’s unlikely that it is being offered, unfortunately\. We recommend following what the course schedule currently says and not requesting a course that is not on Workday\. However, if a change does happen and a course is added later in the summer \(which can occasionally happen\), you will be able to request to switch into it during our add/switch period in August\. You can contact the department directly if you’d like to enquire about whether a particular course will be offered this year\.

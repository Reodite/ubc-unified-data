###   
Class Standing

Class Standing is reviewed on an ongoing basis\. Students in all undergraduate programs except the B\.Sc\. \(F\.N\.H\.\) Dietetics Major will be assigned class standing based on all of the following criteria:  
 

|  |  |  |
| --- | --- | --- |
| **Class Standing** | **Total Credits Completed** | **Required Courses\[1\]** |
| 1 | Fewer than 24 credits | None |
| 2 | Minimum of 24 credits | None |
| 3 | Minimum of 54 credits | LFS\_V 250 |
| 4 | Minimum of 89 credits | LFS\_V 250 |

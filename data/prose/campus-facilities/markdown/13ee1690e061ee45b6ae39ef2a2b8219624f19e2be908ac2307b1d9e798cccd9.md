UBC Facilities is responsible for the planning, development, renewal, and renovation of campus facilities at both UBC Vancouver campus and Okanagan campus\. We collaborate with campus partners and stakeholders, such as the UBC Office of the Provost &amp; Vice\-President Academic, Campus &amp; Community Planning, Treasury, Student Housing &amp; Community Services and [UBC Properties Trust \(UBCPT\)](https://ubcproperties.com/), to provide stewardship for all institutional facilities projects\.

Facilities’ Project Services provide project management services for renovations, renewals and modernization of buildings and campus infrastructure ranging in size from $50,000 to $100 million dollars\. For major new building projects, Facilities engages with UBCPT to manage the design and construction\.

Some of the services provided by the departments responsible for project delivery are core funded; others are customer funded\. [Learn more about our Services\.](https://facilities.ubc.ca/services/)

## Project Services Billing Guidelines

The billing process for Project Services has recently been updated\. For prompt payment, please ensure the following criteria are met:

### Invoice submission

-   Please submit one invoice per email along with all supporting documentation
-   If applicable, please combine the invoice and it’s supporting documentation into one single PDF and send as an attachment via email to: [project\.invoices@ubc\.ca](mailto:project.invoices@ubc.ca)
    -   In the email, please ensure the following information is included in the body or subject line:
        -   UBC Project Number and Project Manager
        -   UBC Contract Number, if applicable \(the contract number starts with SUB and is followed by 4 digits\)

### Invoice details

Please ensure the following information is included on each invoice:

-   UBC Contract Number, if applicable
-   UBC Project Number
-   UBC Project Manager
-   Vendor’s invoice number and invoice date

### Additional requirements, if applicable

#### Consultant invoice

Please include the following with the invoice: documentation for all reimbursable disbursements \(as per UBC Allowable Disbursements Table\) with billing items highlighted\.

#### Contractor invoice\(s\)

**Progress Draw:** Please include the following with the invoice: supporting documents such as Certificate of Payment, valid WorkSafe BC Clearance Letter and Statutory Declaration \(SD\)\. SD is not required for the first progress claim\.

**Lien Holdback Release:** Please include the following with the invoice: Certificate of Completion or Certificate of Substantial Completion along with the same supporting documentation for progress draws\.

**Deficiency Holdback Release:** Please include the following with the invoice: supporting documents, such as Certificate of Payment, valid WorkSafe BC Clearance Letter and Statutory Declaration\.

Questions? Please email [project\.services@ubc\.ca](mailto:project.services@ubc.ca)

### Project Snapshot

**Occupancy:** September 2016  
**Project Manager:** UBC Project Services – Darren Wong  
**Budget:** $263,000

### Project Summary

Project purpose: to improve wheelchair access between the main floor of the IRC building and the elevated Woodward Library entrance\.

A vertical platform lift was installed to improve access to the main level of the Woodward Library\. Previously access to this level was through the use of a ramp which is no longer code complying\.

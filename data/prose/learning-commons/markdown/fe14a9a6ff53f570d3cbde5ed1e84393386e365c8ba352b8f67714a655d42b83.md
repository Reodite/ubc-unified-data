## About This Guide

This guide is an instructional resource intended to assist with access to basic UBC Library resources, with a focus on undergraduate students\.

Those with CWL affiliation \(students faculty and staff\) are highly encouraged to take the [UBC Library Skills Tutorials \(self\-enroll\)](https://canvas.ubc.ca/enroll/F3GKXM)  and the [UBC Library Citation Tutorials \(self\-enroll\)](https://canvas.ubc.ca/enroll/B7AYEN) courses for more tailored information\. 

Graduate students are encouraged to review subject\-specific [Research Guides](https://guides.library.ubc.ca/)\. Community and Alumni please see the [resources below](https://guides.library.ubc.ca/c.php?g=729610&amp;p=5235763#s-lg-box-wrapper-19473044)\.

## Students: Get Started

**If you are a student at UBC, you will find tailored learning in the canvas course:** [Library Skills Tutorials \(self\-enroll\)](https://canvas.ubc.ca/enroll/F3GKXM)

The course is designed to assist all users in becoming more familiar with UBC library\. It has 5 interactive modules with certificates awarded at completion of each module\. Modules are self\-paced and take between 15\-30 minutes each to complete\. Modules can be accessed in any order\. 

-   Module 1: Introduction to UBC Vancouver Library
-   Module 2: Exploring Sources
-   Module 3: Finding Sources \- Basic
-   Module 4: Finding Sources \- Advanced
-   Module 5: Evaluating Sources

## Instructors: Get Started

As instructors, faculty and staff can assign the [Library Skills Tutorials \(self\-enroll\)](https://canvas.ubc.ca/enroll/F3GKXM), [Citation Tutorial \(self\-enroll\)](https://canvas.ubc.ca/enroll/B7AYEN), or individual modules from each\. Options for grading completion for self\-enroll include: requiring students to submit PDF certificates \(generated upon each module's completion\) and/or other activity sheets provided in the modules as proof of completion\.

Instructors can also embed the modules in their courses\. This allows instructors to edit interactive materials such as assignments and quizzes\. [Embed Library Skills Tutorials from Canvas Commons](https://commons-yul-prod.instructure.com/resources/1b533018f69341d8bf73007bcc78c4b2?shared)\. [Embed Citation Tutorial from Canvas Commons](https://commons-yul-prod.instructure.com/resources/1b533018f69341d8bf73007bcc78c4b2?shared)\.

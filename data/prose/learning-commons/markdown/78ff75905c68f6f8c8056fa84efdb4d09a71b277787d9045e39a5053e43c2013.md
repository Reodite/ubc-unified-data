## **Accessibility Statement**

The Chapman Learning Commons is committed to ensuring our website is accessible as possible for all of our users, including those with visual, hearing, cognitive and motor impairments\. We are constantly looking to improve the accessibility and usability of our website and content to ensure equal access for all our users\.

## Accessibility Features

We make sure that our website follows the accessibility best practices provided by the [Web Content Accessibility Guidelines 2\.0](https://www.w3.org/TR/WCAG20/)\. As part of our commitment to accessibility, we do our best to ensure that our website incorporates the following features:

-   Website optimized for users using screen\-reader technology
-   All content can be navigated using only a keyboard
-   Links, headings, tables, and images are compatible with screen readers
-   Images include alt text, describing image content or function
-   Graphs, charts, and maps include contextual or supporting detail
-   Links exiting the website will open in a new tab

## Known Accessibility Issues and Areas for Improvement

The Chapman Learning Commons strives to adhere to the guidelines mentioned\. However, there are some accessibility features which we have not yet been able to incorporate, such as providing detailed descriptions regarding multimedia sourced from an external website\. We hope to ensure that these issues are addressed as soon as possible to provide the best support for our users\.

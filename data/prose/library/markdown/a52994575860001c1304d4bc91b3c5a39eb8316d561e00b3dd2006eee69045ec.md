UBC Library understands the value of persistent identifiers \(PIDs\) in facilitating long\-lasting digital reference to an object, contributor, or organization\. UBC offers supports and services for many types of PIDs\. 

Learn more on the [Persistent Identifier](https://guides.library.ubc.ca/PIDS "https://guides.library.ubc.ca/PIDS") guide about author, object, and institutional level identifiers\. 

Certain UBC departments are eligible to request UBC ISBN's from the Library for departmental publications\. Visit the [ISBN request form](https://ask.library.ubc.ca/isbnrequest/) for more details about this service\.

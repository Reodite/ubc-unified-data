Students can view required readings for their courses using LOCR, the Library's Online Course Reserve system\. View the [Library's Student Resource page on LOCR](https://services.library.ubc.ca/borrowing-services/using-course-reserves/#StudentResources-1) for more information and guides on how to access course readings\. Additional information can be found in the [Learning Technology Hub LOCR Student Guide](https://lthub.ubc.ca/guides/locr-student-guide/)\. 

If you have questions about Course Reserve materials, please [contact Course Reserve staff](https://services.library.ubc.ca/borrowing-services/using-course-reserves/#Contacts-3) for more information\.

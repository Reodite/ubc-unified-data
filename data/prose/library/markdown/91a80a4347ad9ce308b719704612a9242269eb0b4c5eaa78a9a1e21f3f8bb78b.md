UBC Library provides many services for instructors\. This list is not comprehensive, but intended to connect instructors with key contacts in the library:

-   [Subject librarians](https://directory.library.ubc.ca/subjectlibrarians/) provide support with many aspects of teaching and learning
-   [Borrowing services](https://services.library.ubc.ca/borrowing-services/get-library-access/faculty/) are available to all instructors
-   [Library Online Course Reserves \(LOCR\)](https://services.library.ubc.ca/borrowing-services/using-course-reserves/) allows instructors to create a single list with all the course materials\.
    -   Easily add articles, books, web links and media resources or request the Library to add items via the [Syllabus Service](https://services.library.ubc.ca/borrowing-services/using-course-reserves/#fragment-cc8b788e2107211a05cdccf71c302c69-1)
    -   Request the Library to create PDFs of book chapters or upload your own
    -   Get a hyperlink for the course materials that is accessible \(only\) to students enrolled in your course
    -   Reactivate readings in future terms quickly
-   Visit the [Scholarly Communication Open Education](https://scholcomm.ubc.ca/open-scholarship/open-education/) page for information and support with open educational resources \(OERs\)
-   Visit the [Copyright Office](https://copyright.ubc.ca/instructors/) website for resources intended to assist faculty members in applying copyright requirements in a classroom setting
-   Visit the [cIRcle](https://circle.ubc.ca/?login) website to review options for depositing teaching outputs at UBC Library
-   Visit the [Research Data Management](https://researchdata.library.ubc.ca/) website for resources and guidance related to finding, managing, and depositing research data\.

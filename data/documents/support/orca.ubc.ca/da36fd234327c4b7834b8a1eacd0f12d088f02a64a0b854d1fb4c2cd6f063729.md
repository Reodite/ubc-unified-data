1.  [ICCS 014](https://science-orca-2026.sites.olt.ubc.ca/about/rooms/iccs-014/)
2.  [ICCS 008](https://science-orca-2026.sites.olt.ubc.ca/about/rooms/iccs-008/)

## [ORCA Windows machines](https://orca.ubc.ca/about/rooms/#orca-windows-machines)

ORCA machines in ICCS 014, 008, Henn 203, and Henn 312 have the following hardware specifications \(Asus NUC 90AB3ANK i5\-1340P\):

-   Intel i5\-1340P 4\.6GHz,
-   Integrated Video 2xHDMI 2\.0b
-   Crucial 16GB DDR43200mhz SODIMM RAM,
-   Kingston 250GB PCIe 4\.0 NVMe SSD
-   2x USB 4\.0 Type\-C ports
-   4x USB Type\-A ports
-   1x 3\.5mm headphone jack

### [Software available on Windows](https://orca.ubc.ca/about/rooms/#software-available-on-windows)

All PC ORCA machines have Windows 11 installed\.

As of October 22, 2024, the following software is available on all PC ORCA machines:

-   Browser \(Microsoft Edge\)
-   Respondus Lockdown Browser
-   A Dictionary
-   Sketching Program \(Microsoft Paint\)
-   Dr\. Racket IDE
-   Calculator \(Windows calculator with standard mode and scientific mode\), available via a shortcut on the desktop
-   Simple Text Editor \(Notepad\)

## [ORCA Mac machines](https://orca.ubc.ca/about/rooms/#orca-mac-machines)

ORCA Macs have the following hardware specifications \(M4 Mac mini, 2024\):

-   Apple M4 chip
-   16GB unified memory
-   512 GB SSD storage
-   1x 3\.5mm headphone jack
-   5x USB\-C ports
-   [More details here](https://support.apple.com/en-ca/121555)

### [Software available on Macs](https://orca.ubc.ca/about/rooms/#software-available-on-macs)

All Mac ORCA machines will have macOS Tahoe installed\.

## [Document Cameras](https://orca.ubc.ca/about/rooms/#document-cameras)

ORCA machines in ICCS 008 are equipped with a document camera, which allows students to capture high resolution images of student\\ work for manual grading:

-   Kitchbai KB\-700
    -   8 MP still image document camera
    -   4K video capture resolution

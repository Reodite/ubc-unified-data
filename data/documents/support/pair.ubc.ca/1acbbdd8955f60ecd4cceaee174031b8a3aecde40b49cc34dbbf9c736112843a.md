These interactive dashboards contain data to inform the enrolment planning meetings and the admissions process\. **Access is limited**; authorized UBC personnel may request access through: [pair\.team@ubc\.ca](mailto:pair.team@ubc.ca)\.

###### **Access limited to UBC network**

Please note the following interactive dashboard is only accessible to computers on\-campus or via UBC myVPN\.

[Learn how to connect to UBC myVPN](https://it.ubc.ca/services/email-voice-internet/myvpn/how-access-myvpn)

A weekly snapshot of both program enrolment and course registrations, by campus, faculty, program \(headcounts and FTEs\), filter by domestic/international, new to UBC, or indigenous student\.

[view weekly enrolment dashboard](https://reports.im.it.ubc.ca/t/PAIR/views/WeeklyEnrolment/WeeklyEnrolmentTrends)

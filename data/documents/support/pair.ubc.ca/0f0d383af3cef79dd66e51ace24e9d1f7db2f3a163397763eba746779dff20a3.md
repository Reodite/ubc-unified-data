These interactive dashboards contain data to inform the enrolment planning meetings and the admissions process\. **Access is limited**; authorized UBC personnel may request access through: [pair\.team@ubc\.ca](mailto:pair.team@ubc.ca)\.

### [Admissions Funnel](https://pair.ubc.ca/student-data-analytics/admissions-enrolment-planning/admissions-funnel/)

This dashboard provides a tabular snapshot of the current admissions funnel\. Data are from the new Admissions system; registration data and historical comparisons will be added as functionality is built out in Workday\.

### [Enrolment Planning](https://pair.ubc.ca/student-data-analytics/admissions-enrolment-planning/enrolment-planning/)

This dashboard provides historic targets and enrolments, retention, and graduate information to inform the planning meetings\.

### [Weekly Enrolment](https://pair.ubc.ca/student-data-analytics/admissions-enrolment-planning/weekly-enrolment/)

A weekly snapshot of both program enrolment and course registrations, by campus, faculty, program \(headcounts and FTEs\), filter by domestic/international, or new to UBC\.

### [Target Submission](https://pair.ubc.ca/student-data-analytics/admissions-enrolment-planning/target-submission/)

Link to submit baccalaureate &amp; post\-baccalaureate new\-to\-program intake targets for domestic fee\-paying and international fee\-paying students\.

## Historical Data

### [Admissions Tracking Report](https://pair.ubc.ca/student-data-analytics/admissions/admissions-tracking-report/)

This dashboard provides End of Cycle snapshots of historical admissions funnels, including year\-over\-year change\.

### [Admissions Funnel](https://pair.ubc.ca/student-data-analytics/admissions-enrolment-planning/admissions-funnel/)

This dashboard provides details of End of Cycle historical admission funnels, in both individual years and multi\-year trends\.

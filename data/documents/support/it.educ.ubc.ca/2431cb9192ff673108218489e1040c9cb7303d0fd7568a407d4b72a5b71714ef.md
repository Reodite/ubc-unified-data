### 2011/04/15

---

The UBC Campus wide Microsoft Agreement took effect April 1st\.  Distribution details are not entirely finalized, but here is the information to date\.

If you have any questions, please see the [Software Licensing](http://www.it.ubc.ca/services/desktop-print-services/software-licensing "Software Licensing") section of UBC IT’s web site\.

The following products are covered and licensed for use on all UBC owned computers:

-   Microsoft Office \(Windows and Mac OS X\)
-   Microsoft Visio Professional
-   Microsoft Project Professional
-   Windows Server Client Access Licenses
-   Windows OS Upgrade Version

At least initially, installation of these products on UBC owned computers in Education will be done by UBC IT staff\.  
Please contact UBC IT to make arrangements for installation:

-   Contact UBC IT  
    via webform:  
    [it\.ubc\.ca/sos](http://it.ubc.ca/sos)  
    via phone:  
    604\.827\.4357 \(7\-HELP\)

---

In addition to UBC owned computers, UBC faculty and staff who are assigned a UBC owned computer are also eligible to participate in Microsoft’s Software Assurance Home Use Program \(HUP\)\. This program enables you to get a licensed copy of most Microsoft® Office desktop applications \(Office, Project, Visio\) to install and use on one home computer\.

You may continue using HUP software while you are a UBC employee and the Campus licensing is in effect\.

Please note that some product and language versions may not be available at the time you place an order\. For up\-to\-date information on the availability of Home Use Program software, please visit [microsoft\.com/licensing](http://microsoft.com/licensing)\.

To access the Microsoft Home Use Program Web site:

1.  Go to [hup\.microsoft\.com/](http://hup.microsoft.com/)
2.  Select the country to which you want your order to be shipped to and choose the language for viewing the order Web site\.
3.  Enter your UBC e\-mail address \(ie @ubc\.ca or @mail\.ubc\.ca\) and the program code that was sent out via Education lists\.  
    Note: This program code is assigned to UBC for our sole use in accessing this site\. You may not share this number with anyone outside UBC\.  
    If you need the code, please contact UBC IT\.
4.  You will receive an email with a link\.
5.  Via the link sent, you can order HUP software\. A fee will be charged varying on what you choose and whether you wish media\.

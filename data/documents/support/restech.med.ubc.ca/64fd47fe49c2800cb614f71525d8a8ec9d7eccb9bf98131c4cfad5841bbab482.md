## Data Applications with Oracle APEX

[Image](https://med-fom-researchtech.sites.olt.ubc.ca/files/2023/07/Oracleapex_logo_only.png)

**Oracle Application Express \(Oracle APEX\) is a developer\-friendly, low\-code development platform for building data applications \(apps\)\.**

 Using Oracle APEX, developers can rapidly build and deploy fast and secure apps to support research projects\. Programming experience is required to use this platform\.

## What can I use it for?

-   Developing data warehouses for external mobile apps 
-   External data sharing 
-   Datamart reporting 
-   Coalescing multiple research datasets

In the past, Xwi7xwa Library has maintained a list of courses with Indigenous content\. While we will continue to host our [**archived list**](https://xwi7xwa.library.ubc.ca/get-involved/take-a-course/#archived-list) of previous years’ courses on this page, we will no longer be publishing updated course lists\. Please [email Karleen Delaurier\-Lyle](mailto:karleen.delaurier-lyle@ubc.ca) if you have any questions\.

**How to find courses with Indigenous content at UBC:**

Go to the UBC Student Service Centre\. Select “Search,” and from the drop\-down menu, select “Courses\.”

[Image](https://xwi7xwa-library-10nov2016.sites.olt.ubc.ca/files/2023/09/Screenshot-2023-09-18-132604-247x300.png)

Use the “Keyword\(s\)” field to input relevant keywords, and fill out the rest of the search as needed \(ie\., only Wednesday classes, etc\.\)\.

Some relevant keywords to search include:

-   Indigenous
-   First Nations
-   Inuit
-   Metis
-   First Nations Endangered Languages
-   Decolonizing
-   Anti\-colonial

You can also **search by Instructor**\. UBC maintains a list of Indigenous faculty members [**here\.**](https://indigenous.ubc.ca/faculty/indigenous-faculty/?login)

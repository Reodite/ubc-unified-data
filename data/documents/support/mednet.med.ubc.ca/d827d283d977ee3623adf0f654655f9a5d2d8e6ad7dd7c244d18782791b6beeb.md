Learner

Open Close

Take a moment to explore the primary navigation bar\. The options have changed, but all the same functionality is still available\.

[Image](https://med-fom-mednet.sites.olt.ubc.ca/files/2026/03/Picture1.png)

**Tip:** Consider using Elentra’s **Bookmark** tool in the sidebar to create quick links for pages you visit often\.

[Image](https://med-fom-mednet.sites.olt.ubc.ca/files/2026/03/Picture2.png)

Course links can now be found under the **Courses tab** in the primary navigation bar\.

[Image](https://med-fom-mednet.sites.olt.ubc.ca/files/2026/03/Picture3.png)

**Tip:** Save your desired course page using Elentra’s **Bookmark** toolfor faster access\.

If you subscribe to a course learning event calendar in Entrada, you will need to subscribe to your calendar again using the new Elentra URL\.

[Image](https://med-fom-mednet.sites.olt.ubc.ca/files/2026/03/image-2.png)

**Tip:** Click “Share Calendar” in the bottom right corner of the dashboard calendar and select the Course which you would like to subscribe to, then click “Copy”\. Use this URL to subscribe in your external calendar of choice

Assignments are now **sorted by Assignment Title as default**, rather than by course\. They can still be filtered or sorted to suit your preference\. 

**Tip:** Use filters if you’re looking for a specific course assignment, or sort the table based on your desired column  

[Image](https://med-fom-mednet.sites.olt.ubc.ca/files/2026/03/Picture4.png)

Event resources can now be found at the bottom of the learning event page\. Scroll down below Curriculum Tags to find slides, documents, or session materials\.

**Tip:** Use the Event Resources “page anchor” on the top left of the sidebar to navigate directly to the Event Resourses section to find slides, documents of session materials\.

[Image](https://med-fom-mednet.sites.olt.ubc.ca/files/2026/03/Picture5.png)

To support the migration to Elentra, the FLEX Catalogue will move to a new site\. **You should expect a different look and feel but no changes to current functionality**\. You will be able to access to the new site via your usual links in each FLEX Course Community\. The profile link to “My FLEX Dashboard” will no longer be available\.

[Image](https://med-fom-mednet.sites.olt.ubc.ca/files/2026/04/FLEX-Screenshots-940x412.png)

You may be prompted to log in again with your CWL\. Further details can be found in the FLEX Coursebooks\.

The default sort on the **Grading Tasks** page now shows **the oldest cohort first** instead of the most recent\. 

**Tip:** To grade the latest cohort, scroll to the bottom of the Grading Tasks page\.   
Check the task heading to confirm that you’re grading the correct group \(e\.g\., *Year 1 Class of YYYY, July 1, 2025 – June 30, 2026*\)\.

## CSS uility classes

CSS classes that can help add design characteristics\.

View:

Expand All

Collapse All

```
.is-style-fill-container
```

Intended to be added to feature images in query loop post templates\.

Makes an image 100% wide and 100% tall\. Fills the space and keeps the images aspect ratio\.

Use this on Feature images to make them fill the space\. Otherwise the image will render inside of a 16:9 container\. Empty space is filled with a background image\.

Class:

```
.table-text-wrap
```

For use on tables\.

Sets the `white-space` property to it’s initial value\. This lets text wrap inside of a table cell instead of expanding the table’s width\.

Class:

```
.natural-images
```

For use on images or elements that contain images\.

Removes height and fit specifications from CSS\.

Class:

```
.underlined
```

When added to text, it adds an underline\.

Class:

```
.red-text
```

For text that needs to be marked as important or required\. Changes the text color to red\.

Class:

```
.contact-grid
```

Format a group of columns like a table with striped rows\. Will expand any column with a ‘mailto’ link to fit\.

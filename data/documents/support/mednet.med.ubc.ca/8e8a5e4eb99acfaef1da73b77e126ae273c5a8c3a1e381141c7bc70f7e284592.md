## Introduction

Read Only access allows users the ability too review data in the TTPS\. This role does not have access to action in the tracking to validation workflow\.

Read Only access will allow users to search and view the following;

-   Individual teaching events \(Activity Tracks\)
-   Service provider personal profile information
-   Service provider payee information

As a TTPS user you are expected to use the data responsibly by;

-   Respecting privacy/confidentiality of personal information
-   Only using data in the TTPS for relevant UBC\-related tasks
-   Flagging potentially invalid or inconsistent profile information and reporting it to [the appropriate department](https://med-fom-mednet.sites.olt.ubc.ca/teaching/teaching-tracking-payment/supporting-clinical-faculty/) and/or [Capture Support](https://mednet.med.ubc.ca/Teaching/TeachingTrackingPayment2/TTPGuide/Pages/For-Capture-Support-and-Information-Analysts.aspx) [representative](https://med-fom-mednet.sites.olt.ubc.ca/teaching/teaching-tracking-payment/creating-profiles-payees/)

A full explanation of the responsibilities of all roles in the TTP process can be found in the [TTP Roles and Responsibilities](https://med-fom-mednet.sites.olt.ubc.ca/files/2022/09/TTP-Roles-and-Responsibilities.pdf) document\.

## Clinical Faculty Profile Information

Approximately 12,000 clinical faculty members provide their services to the UBC Faculty of Medicine across the province\. Ensuring we have up\-to\-date information about these clinical faculty members in the TTPS requires participation from all departments, units and sites\.

If you encounter any issues or have questions when navigating the TTPS, please contact [TTP Support](mailto:ttp.support@ubc.ca)\.

Alternative text, commonly called alt text, communicates the purpose or essential information of an image to people who cannot see it\. Screen readers announce alt text when scanning a page, and it can also help if an image doesn’t load\.

## How to add alt text to an image

Alt text is managed in WordPress’ Media Library—not through an Elementor component\.

1.  Go to the websites dashboard
2.  Navigate to Media
3.  Select the desired photo
4.  Ensure More Details is selected
5.  Alt text should be visible with a field next to it, use this space to add the desired alt text

The alt text will save automatically, you don’t need to select “update”\.

## Write useful alt text

Good alt text gives a visitor the information they would miss without the image\. Use these practices:

-   Describe the image’s purpose in the context of the page
-   Use a short phrase or sentence
-   Use plain, natural language and appropriate punctuation
-   Avoid beginning with “image of”, “picture of” or “photo of”\. Screen readers already identify an image as an image\.
-   Do not add keywords for search engine optimization\. Alt text must serve the image’s actual purpose\.

## Use respectful and accurate descriptions

Alt text should be accurate without making assumptions about the people, communities or cultural materials shown\.

-   Do not guess a person’s identity, gender, disability, cultural affiliation or relationship to others based on appearance\.
-   Identify people only when their identity is relevant, known and appropriate to include\.
-   Describe visible actions and relevant surroundings instead of relying on subjective impressions such as “inspiring”, “successful” or “happy”\.
-   For Indigenous artwork, use the artwork’s correct name and the artist’s stated identity when this information is known\. Do not interpret cultural symbols or meanings unless that interpretation comes from an authoritative source\.
-   Keep image credits, permissions and detailed attribution in a visible caption or credit line rather than placing all of that information in alt text\.

### Alt text, captions and credits are different

These fields can support one another, but they serve different purposes:

|  |  |
| --- | --- |
| **Field** | **Purpose** |
| Alt text | Provides an equivalent for the image when it cannot be seen\. |
| Caption | Provides visible context, identification or explanation for all visitors\. |
| Credit | Identifies the photographer, artist, source or rights holder as required\. |

## Avoid using images of text

Whenever possible, enter headings, event details, instructions and other important information as real page text rather than placing the words inside an image\. Real text can resize, translate and be read more reliably by assistive technologies\.

If an image must contain essential text, include that information in the alt text or nearby page content\.

## Examples

#### Portrait on a profile page

**Alt text:** Dr\. \[Name\] stands beside a materials\-testing machine in a UBC Okanagan engineering lab\.

Why: The person’s name and research setting are relevant to the profile\.

#### Campus image used only as a page divider

**Alt text:** Leave the alt text field empty\.

Why: The image adds visual interest but no new information\.

#### Image linking to an application page

**Alt text:** Apply to the Bachelor of Science program

Why: The alt text describes the link destination or action\.

#### Event poster

**Alt text:** Graduate research conference, October 18, 9 am to 4 pm, UNC Ballroom

Why: Essential poster information must also appear as page text\.

-   Accessibility and usability \| Copywriting \| Page layouts and components

-   September 1, 2026

Clear link text and button labels help users understand what will happen before they select an element\. This is especially important for people who scan pages, navigate with a keyboard or use assistive technology such as a screen reader\.

Regardless of the element you choose, its visible label should describe the destination or action\. 

## Write link text that makes sense on its own

People often scan a page instead of reading every sentence\. Screen readers may also review a list of links without the surrounding paragraphs\. Generic wording such as “click here”, “more” or “read this” does not explain the destination when it appears out of context\.

|  |  |
| --- | --- |
| **Avoid** | **Use instead** |
| Click here | Review undergraduate admission requirements |
| Learn more | Explore graduate programs |
| Read more | Read the research story |
| Download | Download the campus map \(PDF\) |
| More information | View tuition and fee information |
| Go | Register for the workshop |
| Submit | Send feedback |

### Describe the destination or action

Use concrete words that reflect what users will find or do\. Helpful labels include:

-   View the course schedule
-   Apply to UBC
-   Register for orientation
-   Email the Web and Communications team
-   Download the annual report \(PDF\)
-   Save changes

For downloadable files, include the file type when it helps users decide whether to open the link\.

### Keep labels concise and specific

Link text and button labels should be brief, but not so brief that the meaning disappears\. Link the meaningful phrase rather than an entire sentence or paragraph\.

-   Use: Review the student application guide\.
-   Avoid: To review the student application guide and learn more about the process, click here\.

### Use consistent wording and styling

Use the same label for the same action throughout the website\. Do not alternate between “Apply now”, “Start an application” and “Begin” when all three controls perform the same task\.

Links must also be visually identifiable\. Keep the approved link and button styles\.

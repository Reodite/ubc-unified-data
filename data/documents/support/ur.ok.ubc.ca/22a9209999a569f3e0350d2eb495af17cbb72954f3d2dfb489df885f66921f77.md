Child pages and related links help users move through connected information\. Use both deliberately to help users understand where information belongs and where they can go next\.

Child pages and related links also help support a healthy sitemap and navigation\. By creating pages that represent unique intentions, you can avoid overwhelming users with too much disparate information\.

## Use child pages to create a clear hierarchy

A child page should cover a distinct part of the broader subject introduced by its parent page\. Base parent\-child relationships on how users understand the content rather than your unit’s internal structure\.

For example:

-   Admissions &gt; Undergraduate admission requirements
-   Research &gt; Research centres
-   Student services &gt; Academic advising
-   About &gt; Contact and locations

Keep the hierarchy as shallow as practical\. Users should not need to move through several levels of overview pages before reaching useful information\.

### Make parent pages useful

A parent page should help users understand the broader subject and choose where to go next\.

Depending on the content, a parent page may include:

-   a brief introduction to the section,
-   important information users need before choosing a path,
-   clear links to child pages,
-   a primary action when the section supports a common task, and
-   contact information or another next step when appropriate\.

#### Set the parent page in WordPress

The parent\-child relationship is a WordPress page setting, not an Elementor layout setting\.

-   Go to the website dashboard
-   Select Pages
-   Find the desired child page, select Quick Edit
-   Use the dropdown beside Parent to select the desired parent page
-   Select Update

Changing the parent of an existing page may affect its URL, depending on the website configuration\. If the URL changes, arrange an appropriate redirect and update links to the old address\.

## Use related links to support the next step

Related links connect users to useful information without changing the website hierarchy\. Link to authoritative information rather than duplicating it on multiple pages\.

Add a related link when it helps users:

-   complete the current task
-   understand a requirement or topic mentioned on the page
-   compare related options
-   move to a logical next step
-   find a related service or source of information
-   return to a broader section when needed

### Place related links where they are useful

Place links where users are most likely to need them\. Avoid collecting every potentially related link at the bottom of a page as this can overwhelm users or be ignored\.

Possible placements for related links:

-   Within the content: when another page directly supports the information being discussed
-   After a section: when the destination is a logical next step
-   On a parent page: when directing users to child pages within the section
-   Near the end of the page: for a small number of useful secondary destinations

-   Accessibility and usability \| Copywriting \| Page layouts and components

-   September 1, 2026

Readable web pages help people find and understand information quickly\. Clear structure also supports people who use assistive technology and makes a page easier for search engines and other tools to interpret\.

Elementor gives you control over both the structure and appearance of your content\. Choose widgets and HTML tags based on their purpose, then use approved styles to control how they look\.

## Headings

Headings divide a page into meaningful sections\. They help people scan the page and allow screen readers to navigate directly between sections\.

### Use the Heading widget

Use Elementor’s Heading widget for page and section headings\. Do not create a heading by enlarging or bolding text in a Text Editor widget\.

### Follow a logical hierarchy

The page title already appears as the page’s H1—do not add any other H1s to page as this negatively impacts search optimization\.

-   Use H2 headings for the main sections of the page\.
-   Use H3 headings for subsections within an H2 section, H4s for subsections within an H3 and so on\.
-   Do not skip levels, such as moving directly from H2 to H4\.

Choose a heading level based on structure, not on how large you want the text to appear\.

### Write headings that describe the content

A heading should tell users what they will find in the section below it\. Keep headings concise, specific and easy to understand without relying on internal terminology\.

|  |  |
| --- | --- |
| Vague | Clear |
| More information | Application deadlines and required documents |
| Resources | Teaching and learning resources |

Add a heading when the topic changes or when it would help users find a specific section\. Avoid adding a heading for every short paragraph, and make sure all content below a heading relates to it\.

## Lists

Lists make related information easier to scan\. They are especially useful for options, requirements, steps and short sets of supporting details\.

### Choose the right type of list

-   Use a bulleted list when the order of the items does not matter\.
-   Use a numbered list when users must complete steps in sequence or when the order is important\.

### Keep list items consistent

-   Introduce the list with a complete sentence\.
-   Use the same grammatical structure for each item\.
-   Keep items concise and avoid unnecessary nested lists\.
-   Use full punctuation when every item is a complete sentence\.
-   Omit end punctuation when the items are short words or phrases without internal punctuation\.

-   Accessibility and usability \| Using images and media

-   August 28, 2026

Icons and images can help users scan, understand and navigate content, and they should have a clear purpose\.

Choose the visual that best supports the content:

-   use an icon for a simple, recognizable concept
-   use an image when visual context matters, and
-   use text only when a visual does not improve understanding

Before adding a visual, consider what it helps users understand, distinguish or do\. If it is primarily decorative or fills empty space, it may not be necessary\.

## When to use an icon

Icons work best as supporting visual cues for simple, recognizable concepts or repeated patterns\.

Consider an icon for:

-   a short set of services, features or benefits,
-   categories or status indicators,
-   links or actions where a familiar symbol supports a descriptive label, or
-   consistent visual cues across elements or related content\.

Use familiar symbols and keep a visible text label whenever possible\. An icon should support the meaning rather than require users to interpret the symbol on its own\.

### Sourcing appropriate icons

When using an icon, use the icons provided in MediaValet\.

1.  Login to [https://ubc\.mediavalet\.com/](https://ubc.mediavalet.com/)
2.  Go to Library &gt; UBC Brand Assets &gt; UBC Okanagan &gt; Brand Assets &gt; Icons – Web and Presentation
3.  Use the Colour or Reverse options, depending on how the icon will be displayed
4.  Select the desired graphic
5.  Select Download &gt; Quick Download
6.  Upload the file to your website’s media library
7.  Add appropriate alt text
8.  Add to the page

## When to use an image

Use an image when seeing something specific provides useful information or context that an icon cannot\.

Consider an image for:

-   a person, facility, location or physical space,
-   an activity, object, process or research subject,
-   a story, profile or event where the image adds meaningful context, or
-   relevant imagery that helps users understand the UBC Okanagan experience

Choose images that are specific, accurate and relevant to the content rather than generic imagery used only for decoration\.

## When to use neither

Not every section needs a visual\. Clear headings, typography and spacing often provide enough structure on their own\.

Consider text only when:

-   an icon would be ambiguous without explanation,
-   only a generic or unrelated image is available,
-   the visual repeats what the nearby heading or text already communicates, or
-   the visual adds clutter without helping users understand or navigate the content

Avoid adding icons or images simply to make every section visually different or to fill empty space\.

### Keep visual patterns consistent

When several related items appear together, use the same visual approach across the set\.

Avoid mixing icons, photographs, illustrations, logos or other visual types unless the difference communicates something meaningful\.

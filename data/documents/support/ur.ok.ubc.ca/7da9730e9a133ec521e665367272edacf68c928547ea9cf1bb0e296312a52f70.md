-   Accessibility and usability \| Page layouts and components

-   August 28, 2026

Elementor uses responsive settings to adapt a page across desktop, tablet and mobile devices\. Some of these settings need to be manually built to ensure the content appears properly across the different screens\.

The templates built in the UBC library have the desktop, tablet and mobile settings entered already—no need to do it yourself \(unless you need to make an adjustment\)\.

## Build flexible layouts

Use containers and responsive settings so content can adapt naturally to the available screen width\.

-   Allow side\-by\-side content to stack when needed\.
-   Build content in the order it should appear when stacked\.
-   Use flexible widths rather than fixed widths\.
-   Use Spacer component and padding to create space rather than empty elements or repeated line breaks\.
-   Avoid fixed heights that may clip content when text wraps or is enlarged\.
-   Keep container nesting as simple as practical\.

Use the Structure panel to check the order and nesting of containers and elements\.

### Use Elementor’s responsive settings

Responsive controls may be available for settings such as:

-   container direction,
-   width and alignment,
-   padding and margin,
-   typography, and
-   visibility\.

Adjust only the settings that need to change for a particular screen size\.

#### Keep the same content across devices

Responsive design should change how content is presented, not what’s presented\.

Avoid creating separate desktop and mobile copies of the same section when one responsive version can work\.

### Check images and media

Review images and media at smaller screen sizes to make sure they still support the content\.

Check that:

-   Important subjects are not lost through cropping
-   Images do not overflow their containers
-   Video, carousels and embeds remain usable at narrower widths

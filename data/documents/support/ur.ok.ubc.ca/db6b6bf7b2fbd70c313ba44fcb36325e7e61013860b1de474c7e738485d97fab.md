A table of contents provides in\-page navigation to help users move between sections of a longer page\. Use one when it makes a page easier to navigate, not simply because the page contains a lot of text\.

Build the page structure first\. A table of contents should reflect clear, well\-organized headings rather than compensate for a page that is too broad or poorly structured\.

## Decide when to use a table of contents

A table of contents is normally unnecessary for a page\. However, you may need to consider adding one when a page:

-   contains several substantial sections users may visit independently;
-   is a guide, policy, procedure or detailed reference;
-   covers several related questions or topics under distinct headings;
-   is likely to be revisited for specific information; and
-   requires enough scrolling that in\-page navigation would be useful\.

If the resulting table of contents is long or complex, reconsider whether some content should be moved to a new page\.

### Using the Table of Contents element

Use the Table of Contents template to automatically populate heading links from the page\.

There are a variety of ways to modify the template to ensure it’s only displaying the information you want\. You can:

-   include or exclude subheadings,
-   adjust to numbered or bulleted lists,
-   nest subheadings in a dropdown, and
-   adjust the background colour of the element\.

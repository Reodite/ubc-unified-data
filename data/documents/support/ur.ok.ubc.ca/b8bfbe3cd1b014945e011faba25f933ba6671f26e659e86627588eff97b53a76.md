-   Accessibility and usability \| Copywriting \| Page layouts and components

-   September 1, 2026

Calls to Action \(CTAs\) identify next steps for a user\. This can take many forms—lists, documents or contacts—but is most often presented as a button or hyperlink\.

CTAs are the most common reason a user is visiting a page\. Because of this, we need to make them clear and recognizable\.

## Write labels that describe the action

Begin most button labels with a clear verb and name the thing the user will receive, view or complete\. A label should make sense when read on its own\.

|  |  |  |
| --- | --- | --- |
| **Less effective** | **More effective** | **Why it’s stronger** |
| Learn more | Review admission requirements | Names the information users will find\. |
| Click here | Register for the workshop | Describes the action without referring to a mouse or touchscreen\. |
| Submit | Send your request | Explains what will happen to the information\. |
| Download | Download the annual report \(PDF\) | Identifies the file and its format\. |
| Contact us | Email the advising team | Clarifies how and whom the user will contact\. |

### Support the action with useful context

A call to action usually works best when nearby text explains why the action matters and what users can expect\. The heading, description and button label should work together without repeating the same words\.

|  |  |
| --- | --- |
| **Less useful** | **More useful** |
| Ready to get started? | Applications for the fall term close on January 15\. Review the requirements before you begin\. |
| Learn more | Review admission requirements |

Include important information such as deadlines, eligibility, costs or file formats in the surrounding content\. Do not hide information that may affect a user’s decision behind the button\.

#### Choose between a text link and a button

-   Use a visually prominent button for an important action that helps users continue or complete a task\.
-   Use a text link for supporting information, related content or an action within a sentence\.

## Place calls to action where users need them

Place the action after users have enough information to decide what to do\.

A primary action may appear near the beginning of a straightforward page and again after a longer explanation, but unnecessary repetition can feel distracting\.

-   Place a registration button near the event date, location and eligibility details\.
-   Place an application button after the requirements and deadline are clear\.
-   Place a contact action near the information that may prompt users to ask for help\.
-   Keep related secondary actions near the content they support\.

-   Copywriting \| Page layouts and components

-   August 28, 2026

Create new pages in WordPress, then use Elementor to build and edit the page content\. Keep new pages as drafts until the content, layout and navigation are ready for review or publication\.

Before creating a new page, confirm that the content does not already exist elsewhere on your website and that a separate page is the best way to present the information\.

## Create a new page

1.  Sign in to your website’s WordPress dashboard
2.  Go to Pages &gt; Add New
3.  Enter the page title
4.  Select Save Draft in the top right
5.  Select Edit with Elementor in the top left

### Update the parent page or URL

1.  Go to Pages
2.  Find the desired page
3.  Select Quick Edit
4.  Use the Parent dropdown to select the desired parent page
5.  Use the Slug field to adjust the URL

## Build the page in Elementor

Use a UBC page template layout when possible, which includes pre\-made page layouts to get you started and to create consistency in page construction\.

If there are no adequate page templates to use, ensure the new page’s styles and elements have:

-   global and approved site styles for fonts, colours,
-   H2 headings for main sections and H3 headings for subsections, and
-   the appropriate Elementor elements for your content, keeping the page structure as simple as possible\.

If there is a page layout you like on another site, connect with UR or IT for help in replicating it\.

### Preview and test your page

Before publishing, preview the page outside the Elementor editor and check it at desktop, tablet and mobile widths\.

Confirm that:

-   the page title appears correctly and only once,
-   headings follow a logical hierarchy,
-   links and buttons work and use descriptive text,
-   images and other media display correctly and are accessible,
-   interactive elements work as expected, and
-   there are no empty sections, placeholder content or draft notes\.

### Publish the page

When the page is complete and has gone through the appropriate review process, select Publish\.

After publishing:

-   Open the live URL and check the page as a visitor\.
-   Confirm the layout, links, images and interactive elements work as expected\.

### Program Description

NSERC Alliance Society grants fund projects with societal impact as the main driver\. These grants support research projects led by strong, complementary, collaborative teams that include partner organizations from the private, public and/or not\-for\-profit sectors\. Societal groups representing those affected by the challenge and who can benefit from and use the results of the project must be included, and applications must demonstrate how all interested individuals will learn about and use the products, services or policies that stem from this research\. NSERC provides up to 100% of the funding\. Projects can be 1\-5 years in length, and researchers can request between $20,000 and $500,000 from NSERC annually\. Applications can be submitted anytime\. Note that all applications with private sector partners must include a validated National Security Risk Assessment form, to be included when submitting an RPIF\.

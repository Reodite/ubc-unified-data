UBC students created project for controlling access to machinery in the Mechanical Engineering machine shop\. The project has three components:

-   A Raspberry Pi equipped with an RFID reader and a relay\. An open source booking software with API that allows for programmatical interaction with this booking site\.
    
-   A server running various open source software components that represent the heart of the administrative interface\.
    
-   A registered user can make a booking on the booking site and claim the booking by presenting an RFID token to the reader\.
    

The interacting between the administrative site and the booking site is automated\. Once a user is registered in the admin database, the booking site will update with the data on record\. This separation of the booking system and the admin site allows for great flexibility on what services the system can provide\. For more information, please contact the developer via GitHub\.

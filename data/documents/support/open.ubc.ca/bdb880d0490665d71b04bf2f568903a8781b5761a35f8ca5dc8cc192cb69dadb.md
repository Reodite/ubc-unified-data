LaTeX is a method best known for typesetting mathematical equations but it can also be used to typeset an entire document\. Its plain text commands allow authors to write a variety of symbols quickly and allow authors control over formatting and alignment\. Additionally, LaTeX is free, has good documentation, and has a large active community which has developed a range of freely available modifications called “packages”\.

# *Getting started* How do I get started?

### Overleaf

Similar to other markup languages like [HTML](https://www.w3schools.com/html/html_intro.asp), the styles, contents and layout in a LaTeX document are written using tags or commands\. If you want to use LaTeX to create an entire document or project, you will need to use a program or platform which will recognize and interpret LaTeX tags and commands into a readable document\. We recommend the website [Overleaf](https://www.overleaf.com/) which provides a platform for you to begin creating your LaTeX document\. Overleaf provides many different templates to get your started with your project, as well as in\-depth guides on how to write and use LaTeX\. If you do not want to use Overleaf, they provide a list of [alternate options\.](https://www.overleaf.com/learn/latex/Choosing_a_LaTeX_Compiler)

### Pressbooks

If you don’t want to create your whole document using LaTeX, or want a more intuitive or familiar interface for creating a text, we recommend using [Pressbooks](https://pressbooks.bccampus.ca/)\. Pressbooks is an online platform for creating and publishing open textbooks available at UBC [through BCcampus](https://open.bccampus.ca/create-open-textbooks/using-pressbooks/)\. Pressbooks has an optional plugin called [QuickLaTeX](https://quicklatex.com/) which enables the use of LaTeX within the editor\. Once QuickLaTeX has been enabled, there are several ways you can mark out LaTeX code within the chapter\. One way is to:

1.  At the top of the page write **[Image](https://s0.wp.com/latex.php?latex&amp;bg=ffffff&amp;fg=000000&amp;s=0)** to let Pressbooks know that there is LaTeX code on this page
2.  Add a a dollar sign **\($\)** before and after the LaTeX or,
3.  Put the formula on a new line by adding the following to the beginning and end of you our LaTex equation:

```
\begin{equation}
```

```
\end{equation}
```

For an in\-depth explanation and examples, read [Equations and Formulas: How to Use LaTeX](https://eduguide.pressbooks.com/chapter/equations-and-formulas/)

Another textbook creation platform used at UBC is [Jupyter Notebooks](https://ubc.syzygy.ca/), which allows you to create and share documents that contain live code, equations, visualizations, and narrative text\. ### LaTeX Packages

While the basic symbols available in LaTeX cover most of the bases for math equations, you may find that you need a symbol or need to write something that isn’t included in basic LaTeX\. This is where packages come in\. Packages are add\-on features for LaTeX that contain extra LaTeX commands and programming which add new styling features or modify those already existing\.

To add a package to your LaTeX project, you will need to insert the code in [the preamble](https://latex.wikia.org/wiki/LaTeX_preamble)\.

```
\usepackage{name-of-package}
```

The preamble is the first section of an input file, before the text of the document itself, in which you tell LaTeX the type of document, and other information LaTeX will need to format the document correctly\. [Adding packages in Pressbooks](https://pressbooks.bccampus.ca/pressbookslatex/part/more-advanced-documents/) can be done through the settings menu\. Jupyter Notebooks uses MathJax to render LaTeX and cannot use packages\.

                | **VMWare Fusion No Longer Available** |
                
                |  |
                | --- |
                | Kivuto has removed VMWare Fusion from the Forestry OnTheHub web store, thus students using a Macbook computer can no longer get free VMware Fusion to run Windows applications\. For Intel\-based Macs, there is VirtualBox\. However, for M1/2 silicon\-based Macs, there is currently no free equal\. Please be aware of this new issue if you are planning on requiring students to use Windows applications in your course for the upcoming term\. We will provide further updates as they come in\. If you have any further questions, please contact Carl Johansson, Director of IT Services, at [carl\.johansson@ubc\.ca](mailto:carl.johansson@ubc.ca?subject=VMware%20Fusion%20Support)\. |

                | **April 2024 Final Exam Schedule** |
                
                |  |
                | --- |
                | The Final Exam Schedule dates have been posted on the [SSC](https://ssc.adm.ubc.ca/sscportal/servlets/SRVSSCFramework), the [Exam Website](https://students.ubc.ca/enrolment/exams) and on the [FSC](https://ssc.adm.ubc.ca/fsc/servlets/SRVFSCFramework) under the class list area\. Locations will be updated by mid\-March\. For more exam resources, please refer to our tipsheets regarding [Exam Policies](https://teachingsupport.forestry.ubc.ca/files/2023/12/Tipsheet-Exam-Policy.pdf) as well as [Technical Exam Logistics](https://learningsupport.sites.olt.ubc.ca/files/2023/12/Tipsheet-Technical-Tips-for-Exam-Logistics.pdf)\. These and other exam tipsheets can be found on our [assessment strategies page](https://teachingsupport.forestry.ubc.ca/assessment-strategies/)\. If you need technical support for exams \(e\.g\., using LockDown Browser\), please contact [forestry\.tls@ubc\.ca](mailto:forestry.tls@ubc.ca)\. |

                | **Turnitin Canvas Integration Pilot** |
                
                |  |
                | --- |
                | We are piloting a new feature that enables instructors to integrate Turnitin submissions through Canvas Assignments and generate plagiarism reports directly within SpeedGrader\. If you are interested in piloting this feature or have any questions, please contact [forestry\.tls@ubc\.ca](mailto:forestry.tls@ubc.ca)\. It is free for instructors, and can be enabled for any of your Winter Term 2 courses\. As a reminder, UBC will be maintaining its [decision not to enable the Turnitin AI detection features](https://lthub.ubc.ca/2023/04/04/ubc-not-enabling-turnitins-ai-detection/)\. |

                    | **Concurrent licensing retirement of ESRI ArcGIS Pro** |
                    
                    |  |
                    | --- |
                    | ESRI ArcGIS Pro is retiring concurrent licensing starting midnight on **April 30**, affecting undergraduate computing labs\. Users, including faculty, staff, grads, and soon undergrads, will need to obtain a named user license \(NUL\) by contacting [gis\.forestry@ubc\.ca](mailto:gis.forestry@ubc.ca)\. Instructors conducting undergraduate labs must request ArcGIS class accounts at least two weeks before the lab start date\. Class accounts will be disabled after the course’s final exam\. |
                    
                    |  |
                    | --- |
                    | **UBC Zoom &amp; Teams Video Retention Policy** |
                    
                    |  |
                    | --- |
                    | Starting in October 2023 and March 2024 respectively, UBC will begin removing video recordings from Microsoft Teams and Zoom automatically, one year after each video is recorded\. [Detailed information can be found here](https://lthub.ubc.ca/2022/10/28/zoom-and-microsoft-teams-video-retention-policy/)\. More information about alternative storage, recovery of deleted recordings, previous lecture recordings, and frequently asked questions can be found in [this document](https://learningsupport.sites.olt.ubc.ca/files/2023/06/Zoom_and_Teams_Video_Retention.pdf)\. For further questions, please contact [forestry\.tls@ubc\.ca](mailto:forestry.tls@ubc.ca)\. |

                    | **UBC’s Student Mental Health Provider** |
                    
                    |  |
                    | --- |
                    | [Here2Talk](http://here2talk.ca/) is the new student mental health assistance provider\. It allows UBC students to have immediate access to counselling and community referral services across phone, online chat, and mobile app\. Its services are free and available 24/7, in multiple languages\. |

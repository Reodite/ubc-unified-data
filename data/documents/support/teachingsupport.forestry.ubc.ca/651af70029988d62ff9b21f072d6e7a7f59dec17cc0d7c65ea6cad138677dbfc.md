                | **Forestry Teaching Innovation Fund** |
                
                |  |
                | --- |
                | The **Forestry Teaching Innovation Fund** \(FTIF\) has been launched\. The FTIF aims to support innovative teaching practices, experimentation with pedagogical approaches, and the application of emerging learning technologies in the Faculty of Forestry\. Applications from full\-time lecturers and tenure\-stream faculty in Forestry are welcome, with a deadline of **Friday, November 19, 2021**, and may be submitted using the following [application form](https://learningsupport.sites.olt.ubc.ca/files/2021/10/Forestry-Teaching-Innovation-Fund-FTIF-Application-Form.docx)\. For more information, please click [here](https://learningsupport.sites.olt.ubc.ca/files/2021/10/Call-for-proposals-_Forestry_Teaching_Innovation_Fund-2021-2022.pdf)\. If you have any questions regarding this fund, please contact Michelle Zeng, Senior Manager, Education Strategies \(michelle\.zeng@ubc\.ca\)\. |

                |  |
                | --- |
                | If you are preparing 2021W2 courses and your classroom is in the Forest Sciences Centre or CAWP, the TLS team will support you in the classroom AV system testing\. Please get in touch with michelle\.zeng@ubc\.ca or forestry\.tls@ubc\.ca for a demonstration or dry run\. Information provided by UBC Learning Spaces can be found [here](https://learningspaces.ubc.ca/recording-and-streaming-classrooms)\. The general AV Help Desk contacts are: AV Help Desk: 604\.822\.7956 \| [av\.helpdesk@ubc\.ca](mailto:av.helpdesk@ubc.ca)\. |

                | **Students as Partners Fund** |
                
                |  |
                | --- |
                | The [Student as Partners](https://sap.ubc.ca/) \(SaP\) fund provides Students as Partners in Course Design funding, which supports UBC undergraduates to re\-design UBC Vancouver courses\. The submission deadline for the first round of proposals is from **Jan 10, 2022** to **Feb\. 1, 2022**\. The second round of proposal submissions is available from **February 2022** to **June 2022\.** To provide more information on the application process, there will be an information session held by the CTLT in mid to late November, specifically for the Faculty of Forestry\. For more information, please contact Michelle Zeng at michelle\.zeng@ubc\.ca\. |

                | **Open Educational Research Grants** |
                
                |  |
                | --- |
                | The application deadline for the OER implementation Grants is **3pm, Friday, November 25th**\. The applications for the OER Rapid Innovation Grants are accepted on a **rolling basis** until the funds are exhausted\. For more information visit the OER fund [website](https://oerfund.open.ubc.ca/call-for-applications-for-open-educational-resource-grants-2021/)\. |

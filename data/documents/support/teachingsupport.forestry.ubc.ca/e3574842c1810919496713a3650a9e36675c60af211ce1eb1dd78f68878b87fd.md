                | **MyLA Pilot Seeking Participants** |
                
                |  |
                | --- |
                | The LT Hub is seeking instructors to test [student dashboards](https://er.educause.edu/articles/2021/7/show-students-their-data-using-dashboards-to-support-self-regulated-learning?utm_source=Selligent&amp;utm_medium=email&amp;utm_campaign=er_content_alert_newsletter&amp;utm_content=07-21-21&amp;utm_term=_&amp;m_i=B6i3xcAcG1bsWiM9RoVSePG_91wSbHDLEkEQqL5SbowXcto9A4Dx_5czyRD4PVSX_TX6%2B2peiF%2BW4_C6kBYsTTK4lIlLmvSBBL&amp;M_BT=5551576762) in their Canvas courses using My Learning Analytics for the upcoming academic year, with the purpose of encouraging behavioural patterns that may improve academic outcomes\. To find out more about the pilot and these dashboards, please click [here](https://lthub.ubc.ca/initiatives/technology-pilots/)\. If you have any other questions about this pilot, please contact Michelle Zeng \([michelle\.zeng@ubc\.ca](mailto:michelle.zeng@ubc.ca?subject=Forestry%20Teaching%20and%20Learning)\)\. |

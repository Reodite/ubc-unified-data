                | **Call for Proposals for Small TLEF Fund** |
                
                - **Row 1**
                
                  - **Cell 1:**
                  
                    Proposal submissions for Small Teaching and Learning Enhancement Fund \(TLEF\) Innovation projects are open to faculty, students, and staff at UBC Vancouver\.  
                    The deadline for proposals is **3pm on Nov 14, 2024\.**
                    
                    Small TLEF aims to support the experimentation of pedagogical approaches that will improve innovation in teaching and learning\. Learn more about Small TLEF and how to apply by visiting the [TLEF website](https://tlef.ubc.ca/application/)\.

                - **Row 1**
                
                  - **Cell 1:**
                  
                    UBC Vancouver faculty and staff are invited to apply for Open Educational Resource \(OER\) grants to support course material affordability and innovation\.
                    
                    **OER Affordability Grants:** for addressing course material affordability and access in credited courses through OER\. Deadline: **Jan 16, 2025, at 3pm**\. [Learn More](https://oerfund.open.ubc.ca/oer-affordability-grants/)\.

                - **Row 1**

                | Academic Integrity &amp; AI |
                
                |  |
                | --- |
                | Please visit the [UBC Academic Integrity webpage](https://academicintegrity.ubc.ca/chatgpt-faq/) for academic integrity cautions about using AI tools\. A reminder that the use of AI tools at UBC is a **course\- or program\-level decision**\. Students should **not** assume that all available technologies are permitted\. The use of AI tools does **not** automatically equate to academic misconduct at UBC\. |
                
                |  |
                | --- |
                | **About AI Detectors** |
                
                |  |
                | --- |
                | UBC discourages the use of AI detectors on student work due to concerns over accuracy, privacy, and potential limitations\. AI detectors should **not** be the sole factor for academic misconduct decisions\. |
                
                |  |
                | --- |
                | **Tips for Assignment Design** |
                
                - **Row 1**
                
                  - **Cell 1:**
                  
                    To **mitigate AI use**, you can consider more in\-person activities \(e\.g\., presentations, interviews, discussions\), and/or implement in\-person exams \(e\.g\., Canvas Quiz with LockDown Browser\)\.
                    
                    To **integrate AI use**, instructors need to specify acceptable uses \(e\.g\., brainstorming, data analysis, etc\.\), and can remind students to [cite AI sources following the UBC Library Guide](https://guides.library.ubc.ca/GenAI/cite/) with a limit \(e\.g\., &lt;5 AI citations\)\.
                    
                    More tips can be found on [this CTLT webpage](https://ai.ctlt.ubc.ca/assignment-and-assessment-design-using-generative-ai/)\.

                | **Student as Partners Fund** |
                
                |  |
                | --- |
                | The Student as Partners \(SaP\) Fund supports UBCV undergraduate students in collaboration with faculty to redesign UBCV undergraduate courses\. The proposed budgets must not exceed $7,100 per course\. Visit [SaP’s website](https://sap.ubc.ca/) for more details\. All applications should be submitted to SaP’s [application portal](https://apply.academic.ubc.ca/prog/sap-fund-cdg/) by **February 24, 2023, at 3:00 PM**\. |
                
                |  |
                | --- |
                | **Scholarship of Teaching &amp; Learning Dissemination Fund** |
                
                |  |
                | --- |
                | The fund supports the publications of research on teaching and learning in higher education with direct implications for UBC\. The call is open on a rolling basis\. More information can be found [here](https://isotl.ctlt.ubc.ca/services/sotl-dissemination-fund/)\. |

                | **2023 UBC CTLT Spring Institute Call for Proposals** |
                
                |  |
                | --- |
                | CTLT invites proposals that demonstrate purposeful innovation in teaching practices, educational research, student services, and learning technology that support student success and experiences\. For more information, please visit [Spring Institute Call for Proposal page](https://institute.ctlt.ubc.ca/spring-institute/spring-institute-call-for-contributions/)\. Please submit your proposal by **noon on March 14, 2023** using the [proposal submission form](https://institute.ctlt.ubc.ca/2023-spring-institute-call-for-contributions/)\. |

                    Second Prize \| **$2,500**

                    Killam Award Certificate \| **$1,000**
                    
                    **Consolidated Deadline:** Friday March 3, 2023 \(11:59 PM\)\.

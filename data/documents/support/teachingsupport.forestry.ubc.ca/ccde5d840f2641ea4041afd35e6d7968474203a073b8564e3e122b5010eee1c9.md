                | **Launch of Enhanced CWL on UBC VPN** |
                
                - **Row 1**
                
                  - **Cell 1:**
                  
                    As part of the ongoing effort to enhance  
                    cybersecurity, starting on **July 11, 2022**, Enhanced CWL will be implemented on UBC’s Virtual Private Network \(VPN\)\. When you attempt to connect to the VPN, you will be asked to verify the login using a secondary method in addition to your password\.
                    
                      
                    For more information, please visit the Enhanced CWL page [here](https://privacymatters.ubc.ca/secure/enhancedcwl) or contact your local IT team\.
                
                |  |
                | --- |
                | **IT Bulletins Site** |
                
                - **Row 1**
                
                  - **Cell 1:**
                  
                    In March 2021, Status Page \(hxxps://status\.it\.ubc\.ca\) was launched to replace the legacy IT Bulletins site\. The IT Bulletins Site will now be decommissioned on **July 18, 2022**\.  
                    If you currently use an embedded RSS feed of the IT Bulletins, please switch over to the Status Page general RSS feed \([here](https://status.it.ubc.ca/history.rss)\)\.
                    
                      
                    Users can now subscribe to the RSS feed in multiple ways, including push notifications\.  
                    These options include SMS messaging, email notifications, etc\. If you have any questions, please reach out to the [LT Hub](mailto:LT.hub@ubc.ca)\.
                
                |  |

                | **Name Changes in Canvas and Other Services** |
                
                - **Row 1**
                
                  - **Cell 1:**
                  
                    LT hub is updating how learning technology systems at UBC determine what name to display for you\. These changes will be implemented on **July 27, 2022**\.  
                    
                    If you are a faculty or staff member working for UBC, you can [set your preferred first and last name in Workday](https://ubc.service-now.com/selfservice?id=kb_article&amp;sys_id=5830be9c1b089d509068c992604bcb55&amp;table=kb_knowledge)\. Canvas and other technologies will use this name\.
                    
                      
                    Learn more about the update [here](https://lthub.ubc.ca/2022/07/04/potential-change-to-your-name/?login)\.

                Ungrading – Revisited
                
                |  |
                | --- |
                | **Workshop Recap** |
                
                |  |
                | --- |
                | On May 5th, a workshop discussing ungrading and alternative approaches to grading was co\-hosted by the Faculties of Forestry and Science\. Examples of ungrading in the classroom were shared, as well as discussions surrounding types of grading and the concept of ungrading\. To learn more, please view the presentation slides and workshop recording, found [here](https://teachingsupport.forestry.ubc.ca/news-events/alternative-assessment-strategies-to-help-students-stop-worrying-about-grades-and-focus-on-learning-instead/)\. |
                
                |  |
                | --- |
                | **More Information** |
                
                - **Row 1**
                
                  - **Cell 1:**
                  
                    There are currently over 80 members in the UBC Ungrading and Alternative Grading Slack Community of Practice\. Join us to hear about our trials and tribulations, and also ask the community for questions and get feedback on your ideas [here](https://ungradingatubc.slack.com/join/shared_invite/zt-rjfxgvnl-reMnwPwhoQbhf0LCfC8WPA#/shared-invite/email)\.
                    
                      
                    Ungrading has also been included as part of UBC’s strategic plan for transformative learning \(more information can be found [here](https://strategicplan.ubc.ca/ungrading-a-radical-old-idea-picking-up-steam/)\)\.
                    
                      
                    Other articles on the topic of ungrading can  
                    be found [here](https://theconversation.com/i-no-longer-grade-my-students-work-and-i-wish-i-had-stopped-sooner-179617) \(anecdotal experience\) and  
                    [here](https://www.tandfonline.com/doi/full/10.1080/01443410.2019.1659939) \(academic paper\)\.

                | **Academic Integrity, Privacy, &amp; AI Tools** |
                
                |  |
                | --- |
                | For academic integrity cautions, or guidelines for generative AI tool use in your class, please visit the [Academic Integrity at UBC Chat GPT FAQ page](https://academicintegrity.ubc.ca/chatgpt-faq/)\. For further instructional guidance around optional use for students, please visit the [FAQ item on whether you can require GenAI in your course](https://ctlt-ai-2023.sites.olt.ubc.ca/can-i-require-student-use-of-generative-ai-tools-in-my-course/)\. Please note that a [Privacy Impact Assessment \(PIA\)](https://privacymatters.ubc.ca/privacy-impact-assessment) is required for tools involving personal information at the university\. Instructors can check out [this page for the current state of PIA and any recommendations](https://ai.ctlt.ubc.ca/privacy-impact-assessments-for-generativeai-instructional-use-at-ubc) with regards to teaching and learning uses of generative AI\. Please contact [forestry\.tls@ubc\.ca](https://privacymatters.ubc.ca/privacy-impact-assessment) for consultation and support\. |
                
                |  |
                | --- |
                | **Consider Adding a Statement to Your Syllabus on Generative AI** |
                
                |  |
                | --- |
                | There is no overall ban in using AI tools in teaching and learning at UBC\. As a result, this leaves it as a course\-level decision\. UBC [\(see here\)](https://academicintegrity.ubc.ca/chatgpt-faq/?login) states that students should not assume that all available technologies are permitted, but it also states that the use of ChatGPT or other generative AI tools does not automatically equate to academic misconduct at UBC\. Refer to the [Generative AI Syllabus](https://academicintegrity.ubc.ca/generative-ai-syllabus/) for additional resources and sample statements\. |
                
                |  |
                | --- |
                | **Exam Formats &amp; Planning** |
                
                |  |
                | --- |
                | Instructors are encouraged to consider proactive rather than reactive/punitive ways to prevent and discourage inappropriate use of online web resources or AI in the classrooms\. There are different exam formats \(in\-person paper, in\-person computer, online Canvas, etc\.\) that instructors can consider\. Please refer to the following tip\-sheets: – [Navigating the Choice: Online or In\-Person Assessments](https://learningsupport.sites.olt.ubc.ca/files/2026/02/Navigating-the-Choice-Online-or-In-Person-Assessments-V3.pdf)\. – [UBC Exam Policies, Procedures, and Reminders](https://learningsupport.sites.olt.ubc.ca/files/2023/12/Tipsheet-Exam-Policy.pdf)\. – [Technical Tips for Exam Logistics](https://learningsupport.sites.olt.ubc.ca/files/2023/12/Tipsheet-Technical-Tips-for-Exam-Logistics.pdf)\. |

                | See the latest [IT One Pager](https://teachingsupport.forestry.ubc.ca/files/2023/12/IT-Two-Pager-v12.pdf) for a current listing for IT and related contact info\.                 | **Forestry Trimble Technology Lab Resource Guide** |
                
                |  |
                | --- |
                | [This guide](http://learningsupport.sites.olt.ubc.ca/files/2023/07/2022-University-of-British-Columbia-UBC-Trimble-Technology-Lab-Product-Resource-Guide.pdf) offers a wealth of resources to support the delivery of forestry courses with practical applications\. It includes a range of software tools for 3D modelling, structural analysis, and geospatial data processing\. It also features hardware solutions like integrated smartphone data collectors, mixed reality viewers, and high accuracy GNSS positioning devices\. To subscribe to the software, please email [forestry\.licensing@ubc\.ca](mailto:forestry.licensing@ubc.ca)\. To access the hardware, please reach out to [ht\.li@ubc\.ca](mailto:ht.li@ubc.ca)\. For teaching support, contact [forestry\.tls@ubc\.ca](mailto:forestry.tls@ubc.ca)\. |

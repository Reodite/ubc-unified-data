The most current version of a Canvas supported browser should be used\. In April 2019, Canvas announced that they would no longer support Internet Explorer\. This means that using Internet Explorer or any other unsupported browser may result in features that do not work as intended\. [See a list of web browsers supported by Canvas\.](https://community.canvaslms.com/docs/doc-10720)

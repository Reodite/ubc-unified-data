Personal API tokens are like passwords\. They grant access to your account and should be treated with the same care\. To keep your integrations secure, it’s best practice to regenerate them periodically\. This guide walks you through how to do that\.

1.  Open your Canvas user settings
    -   Log in to canvas\.ubc\.ca with your CWL username\.
    -   Select **Account** from the global navigation sidebar\.
    -   Click **Settings**\.
2.  Locate your existing API tokens
    -   Scroll down to the Approved Integrations section\.
    -   Find the access token you want to regenerate\.
3.  Regenerate the token
    -   Click **Details** next to the token you want to regenerate\.
    -   Click **Regenerate Token\.**
    -   Canvas will generate a new token value that replaces the old one\.
    -   If you don’t see an option to regenerate your token, you can click the **Trash Can** to delete the token\.
4.  Copy and store the new API token securely
    -   Canvas will only display the new token once\.
    -   Copy it and store it somewhere secure \(e\.g\. a password manager\)\.
    -   Treat the API token like a password\.

**LockDown Browser is a web browser that controls what students can do during a Canvas assessment\.** When students use LockDown Browser for an assessment, they will not be able to print or copy questions, visit other websites, access other applications, including tools that create overlays or interact with their screen\. Students will also not be able to close the assessment until it is submitted\. Assessments created for use with LockDown Browser cannot be taken with standard browsers\.

## What can I use it for?

You can use LockDown Browser to help preserve academic integrity in Canvas assessments:

-   Restricting student access in the assessment browser \(e\.g\., no printing, copying questions, accessing other websites\)
-   Sharing exam results and feedback in a locked\-down environment

LockDown Browser is not meant to be used as a remote proctoring or invigilation tool\.

### A note about LockDown Browser

-   **LockDown Browser cannot be used with Zoom\.** Students cannot use both tools at the same time\.
-   **To comply with privacy requirements, you will need to use an advanced setting to lock students into LockDown Browser until the assessment is submitted\.** This setting keeps student data protected throughout the assessment\. For details, see the accordion section [“Require LockDown Browser for a Canvas assessment”](https://ltic.ubc.ca/lt-hub/guides/lockdown-browser-instructor-guide/#require-for-canvas-assessment) below\.

## What do I need to use LockDown Browser?

### A desktop or laptop computer is recommended with LockDown Browser

You can set up assessments in Canvas that use LockDown Browser without downloading it\. However, your students will need to download LockDown Browser, and you may wish to do the same in order to test it using the “Student View” in Canvas\.

LockDown Browser can be [downloaded for Windows or Mac](https://download.respondus.com/lockdown/download.php?id=695714529)\. It can also be [downloaded as an app for iPad](https://apps.apple.com/us/app/lockdown-browser/id659101775), although we recommend discouraging students from using LockDown Browser on iPad, due to the technical difficulties and incompatibilities that can occur\.

LockDown Browser does not run on Linux or on devices using virtualization tools\. This includes virtual machines or software that behaves like one, and even leftover virtualization components can trigger warning\. These setups may stop students from opening the exam or lead to a ban of the student\.

Chromebook and other mobile devices do not work with LockDown Browser at UBC\. You can view the [minimum technical requirements for LockDown Browser](https://support.respondus.com/hc/en-us/articles/4409607170459-What-are-the-computer-requirements-for-installations-of-Respondus-LockDown-Browser-) on LockDown Browser’s support site\.

### A Canvas quiz

Canvas will always call your assessments a “quiz”, regardless of whether you want to assign a quiz or exam to your students\. LockDown Browser works only with Canvas quizzes\.

### Tips

-   **LockDown Browser only restricts what students can do on the device where they are taking the assessment\.** It does not prevent students from using other devices or resources during an assessment\. To ensure academic integrity, additional invigilation is recommended for high\-stakes, closed\-book assessments\.
-   **UBC’s license does not include access to Respondus Monitor—a webcam feature designed to work with LockDown Browser—or its “Instructor Live Proctoring” option\.** This limitation is in line with the [March 2021 Senate decisions to restrict the use of remote proctoring software](https://ltic.ubc.ca/ubcv-senate-motion-proctoring/) on both campuses\.
-   **LockDown Browser can be set up for use in computer labs\.** To get started with the “Lab Edition” of LockDown Browser, please [contact us](https://ltic.ubc.ca/lt-hub/support/lt-hub/) at the LT Hub\.

## How do I use LockDown Browser?

You first need to enable LockDown Browser in your Canvas course, then apply it to the specific Canvas quizzes that you want to be locked down\.

Click any accordion bar below for instructions and tips for using LockDown Browser\.

### Enable LockDown Browser use in your Canvas course

You can enable Lockdown Browser for use in your Canvas course by adding it to your Course Navigation\. This step is necessary for you to use LockDown Browser in Canvas and will not impact what students see\.

1.  Log in to your Canvas course and click **Settings** in the Course Navigation\.
2.  Click the **Navigation** tab\.
3.  Find the “LockDown Browser” menu item, click the **three vertical dots** \(options icon\), and choose **Enable**\.
4.  Scroll to the bottom of the page and click **Save**\.
5.  You will now see the LockDown Browser option in your Course Navigation\. This navigation item is for managing the use of LockDown Browser in the course and will not be visible to students\.

### Prepare students for LockDown Browser assessments

-   **Be clear and specific about your intent for using LockDown Browser\.** Consider explaining these points to students:
    -   LockDown Browser is used to ensure that the assessment experience is fair for everyone by restricting your assessment browser and disabling other applications\.
    -   LockDown Browser runs as a separate program\. You will need to download it ahead of time and can uninstall it when you are done\.
    -   LockDown Browser has passed UBC’s [Privacy Impact Assessment](https://privacymatters.ubc.ca/privacy-impact-assessment) process, meaning it follows UBC and provincial privacy policies\.
-   **Provide a no\-stakes mock quiz that uses LockDown Browser for students\.** This mock quiz will allow everyone to download LockDown Browser and get familiar with the assessment experience *before* using it in a high\-stakes situation\. Having the students test in advance is strongly recommended, as a practice attempt can help identify any software or system conflicts early, when there is still time to address them\.
-   **Explain how students will be able to access any external files, websites, or tools that they will need for the assessment\.** For example, specify where you will upload files \(e\.g\., spreadsheets\), what web domains you will allow access to, or where a calculator can be found\.

#### Tips

-   **Label a LockDown Browser mock quiz clearly\.** This labelling should assure students that they do not need to study, and that the quiz will not count towards their final grade \(e\.g\., “Practice Your LockDown Browser Setup”\)\.
-   **Consider offering a small incentive for completing the mock quiz\.** The more students who practice, the fewer who will need help from you or the teaching team during the assessment period\.
-   **Encourage students to try lots of actions during the mock quiz, mimicking what they might want to do in a real assessment\.** These actions allow students to experience what may happen during an assessment if they try to do anything that you have restricted \(e\.g\., open a website\)\.

### Require LockDown Browser for a Canvas assessment

Canvas will always call your assessments a “quiz”, regardless of whether you want to assign a quiz or exam to your students\. Follow the steps below to set up a Canvas quiz that requires students to use LockDown Browser\.

1.  First, make sure you have an assessment prepared in Canvas\. Follow the [steps for creating an assessment in Canvas](https://ltic.ubc.ca/lt-hub/guides/canvas-instructor-guide/#create-assessment) for help\.
    -   Ensure that no emojis appear in the quiz titles of your Canvas course, as emojis will prevent the LockDown Browser settings from loading in Canvas\. This restriction on emojis applies to all quizzes in your course, whether or not they use LockDown Browser\.
2.  Once you have a quiz in Canvas, click **LockDown Browser** in the Course Navigation of your Canvas course\.
    -   If you don’t see this option, follow the steps in the accordion section above to enable LockDown Browser in your course\.
3.  Click to **Authorize** and, if prompted, click **Continue to LockDown Browser**\.
4.  Find the quiz you would like to require the use of LockDown Browser for, click the **down arrow** to the left of it, and select **Settings**\.
5.  Select **Require LockDown Browser for this exam**\.
6.  To comply with UBC privacy requirements, click **Advanced Settings** and check the **Lock students into the browser until exam is completed** box\. This setting keeps student data protected throughout the assessment\.
    -   With this setting selected, you will also see a warning in the “LockDown Browser” area of your Canvas course when a student exits LockDown Browser during an assessment\. You can review this notification by clicking the **down arrow** beside the quiz name and selecting **Review Early Exits**\. Warnings should not be taken as evidence of misconduct; LockDown Browser may be closed for purely technical reasons\.
7.  Modify optional settings as appropriate to your context, which may include the following:
    -   *Access code for this exam* – Add a password that students must enter before taking the assessment\.
    -   *Require LockDown Browser to view post\-exam feedback and results* – Lock down students when they view quiz outcomes, to prevent them from printing or copying the assessment questions\. This setting only appears for Canvas Classic Quizzes, as results for Canvas New Quizzes must be viewed on LockDown Browser\. Note that this setting does not impact students’ ability to see grades and comments in the “Grades” section of the Canvas course from a standard browser\.
    -   *Allow access to specific external web domains* – Allow students to open specific websites in LockDown Browser during the assessment\.
    -   *Enable Calculator on the toolbar* – Enable a standard or scientific calculator in the LockDown Browser toolbar\.
8.  When you are done, click **Save \+ Close**\. After you save, the assessment will appear with “Requires Respondus LockDown Browser” after the title, and students will need LockDown Browser to complete it\.

#### Tips

-   **LockDown Browser cannot be used during an exam invigilated with Zoom\.** The tools are not designed to be used in coordination, and students will not be able to have both open at the same time\.
-   **Please note to enable LockDown Browser for your Canvas quiz by going to LockDown Browser in your Course Navigation, and not through the Canvas quiz settings\.** You may experience some complications if you enable LockDown Browser only through the Canvas quiz settings\.
-   **In the settings for your Canvas quiz, we recommend adding extra time for students to deal with any technical issues that may arise from using LockDown Browser\.** It is best to add at least 15 minutes to the “Time Limit” and 30 minutes to the period that the quiz is available \(the “Available Until” field\)\.
-   **Please remove any special characters, as well as emojis, from your quiz titles\.** LockDown Browser will try to localize the language of the assessment, and special characters—like those from non\-English languages—will interfere\.

## LockDown Browser FAQ

Find UBC\-specific answers to frequently asked questions by clicking any accordion bar below\.

### When viewing the log for an individual student in Canvas, I see that the student left LockDown Browser during an exam—does this reflect academic misconduct?

No\. Quiz logs in Canvas do not necessarily reflect academic misconduct\. Numerous factors can cause LockDown Browser to close, many of which are purely technical\. A student leaving a quiz cannot be equated to academic misconduct, and LockDown Browser should not be used on its own to ensure academic integrity\.

To access the quiz log for an individual student in Canvas Classic quizzes, click the **quiz name** in Canvas and click the **three vertical dots** \(options icon\) next to the “Edit” button\. Click **Show Student Quiz Results**, click the **student’s name**, then click **View Log**\.

### What should I do if a student tells me they received a LockDown Browser ban?

If a student contacts you saying they received a LockDown Browser ban message, Respondus has temporarily blocked their account after detecting software or system activity that may conflict with the secure testing environment\. A ban is a technical safeguard — it is not an academic misconduct determination\.

A ban prevents the student from opening any assessment that requires LockDown Browser, even in other courses, until the issue is reviewed\. To help the student regain access:

1.  Ask the student for the reference code displayed in the ban message\. This code is required for the LT Hub and Respondus Support to investigate the issue\.
2.  Ask whether any background software may have been running on the student’s device \(e\.g\., virtual machines, sandbox environments, clipboard managers, screen overlays, or AI tools\)\. This can help identify the likely cause\.
3.  Submit a support request to the LT Hub, including:
    1.  the student’s name
    2.  the reference code
    3.  the Canvas course and assessment name
    4.  any details the student shared about the software running on their device
4.  The LT Hub will coordinate directly with Respondus Support to review the case and request ban removal\.

While the ban is being reviewed, you may wish to advise the student that:

-   the ban is linked to their account, not their device — switching computers or reinstalling LockDown Browser will not resolve it\.
-   if their personal device continues to conflict with LockDown Browser, [using a UBC desktop or laptop computer](https://ltic.ubc.ca/lt-hub/guides/lockdown-browser-student-guide/#other-options) may help prevent future issues\.
-   if the ban has affected their ability to start or complete the assessment, you can review the situation with them once the ban is resolved\.

Reassure the student that most bans can be resolved once the reference code is provided and the case is reviewed\.

### How can I test quizzes in LockDown Browser to ensure they work for students?

You can test a quiz that uses LockDown Browser by using the “Student View” in Canvas\. You will first need to [download LockDown Browser on your operating system](https://download.respondus.com/lockdown/download.php?id=695714529) \(Windows or Mac\) and set up your quiz in Canvas to require LockDown Browser\.

You can try taking the quiz by opening the LockDown Browser application, following any instructions to close blocklisted applications, and logging in to Canvas with your UBC CWL \(Campus\-Wide Login\)\. Once you are logged in, go to your course, click the **Student View** button, navigate to the quiz you would like to test, and take the quiz as if you were a student\.

If you would like to know more about your students’ experience, check out our [LockDown Browser student guide](https://ltic.ubc.ca/lt-hub/guides/lockdown-browser-student-guide/)\.

### How can I help students troubleshoot issues with LockDown Browser?

Access issues can sometimes occur with LockDown Browser, especially if it is used on wireless networks with heavy traffic or with web\-conferencing tools such as Zoom\. LockDown Browser can also present accessibility issues for some students, depending on their accommodation needs \(e\.g\., if a student requires access to a spell\-checker\)\.

You can try the following tips\.

-   If LockDown Browser closes for students, have them open it again and attempt to re\-enter the exam\. They can go back to the question they were on using the question list in the sidebar of the Canvas quiz\.
-   If re\-opening the browser works but accessing the exam does not, students can check that LockDown Browser is updated to the latest version\. In LockDown Browser, they can click the info button \(the “i” button\) to update\.
-   If re\-opening the browser does not work, students can [uninstall LockDown Browser](https://support.respondus.com/hc/en-us/articles/4409595418907-How-do-I-uninstall-or-remove-LockDown-Browser) and [download the latest LockDown Browser version](https://download.respondus.com/lockdown/download.php?id=695714529) to install it again\.
-   For students still struggling, you can consider offering a new attempt at the exam that does not require LockDown Browser\. Offering the exam without LockDown Browser may be necessary to meet some students’ exam accommodations\.
    -   [Make a copy of the Canvas quiz](https://community.canvaslms.com/t5/Canvas-Question-Forum/How-to-Duplicate-a-Quiz/m-p/184363#M88659) that requires LockDown Browser, and rename it to make clear this version will not use LockDown Browser\.
    -   Click **LockDown Browser** in the Course Navigation\.
    -   Find the copied quiz, click the **down arrow** to the left of it, and select **Settings**\.
    -   Select **Don’t require Respondus LockDown Browser for this exam**\.
    -   Click **Save \+ Close**\.
    -   [Assign the Canvas quiz to the individual student\(s\)](https://community.canvaslms.com/t5/Instructor-Guide/How-do-I-assign-a-quiz-to-everyone-individual-students-or/ta-p/714) who should take the exam in a regular browser\.

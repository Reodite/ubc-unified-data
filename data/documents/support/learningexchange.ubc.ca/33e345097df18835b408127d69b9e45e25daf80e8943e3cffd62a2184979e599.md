# Learning Exchange website user guide

## Navigation

**Area**: Appearance &gt; Menus

Main menu and side menu are managed through WordPress menus system

-   Main menu
    -   Menu name: Main Navigation
-   Side menu
    -   Menu name: Sidenavigation

## Page Layout

**Area**: Pages

For most pages, content are setup through individual page content with use different key elements\.

### Key elements for page layout

-   Header Image \(wide/ full page width image similar to homepage image\)
    -   Header image are set through **Featured Image**
-   Introduction Paragraph
    -   Larger size introduction paragraph style can be applied through **Blockquote** in page editor [Image](https://learningexchangeaug2018.sites.olt.ubc.ca/files/2018/09/Screen-Shot-2018-09-18-at-3.30.25-PM.png)

-   Section Heading
    -   Section heading uses **Heading 2 \(H2\)** style
-   Subsection Heading
    -   Subsection heading style can be applied by using **Heading 3 \(H3\)**
-   Regular content
    -   Content uses regular **paragraph** style
-   Multiple columns
    -   Multiple columns layout can be created by using
        
        shortcode, see following link for more information:
        

[http://support\.cms\.ubc\.ca/cms\-manual/adding\-content/shortcodes/column\-shortcode/](http://support.cms.ubc.ca/cms-manual/adding-content/shortcodes/column-shortcode/)

### Pages with custom layout

#### Homepage

Homepage uses a combination of widgets and content to create the custom layout

##### Widget controlled area

**Area:** Appearance &gt; Widgets

-   Community Programs
    -   Primary widget
        -   Homepage: Community Programs
-   Page Title \(Light blue region\)
    -   Header widget
        -   Homepage: Heading
-   Homepage call to action \(contact us\) region
    -   Footer widget
        -   Homepage: call to action
-   Event Highlights
    -   Footer widget
        -   Event Highlights

#### Our Team: Profiles

**Area:** Posts

Our team profiles are set up by pulling in individual post with the following information, each person will have their own individual post\.

Post information:

-   Post name: Person’s name to be used in jump link
-   Category: Profiles
-   Profile image: Use **featured image** on each person’s post
-   Profile information:
    -   Name in blue: Use **blockquote** style
-   Custom Fields:
    -   profile\-position: position information to be displayed in jump link
    -   profile\-anchor: jump link anchor
        -   Sample: &lt;a id\=”*post\-id*”&gt;&lt;/a&gt;

*post\-id* can be found in URL, i\.e\. *https://learningexchange…\./post\.php?post\=****12578****&amp;action\=edit*

#### Donate information in Footer

**Area**: Appearance &gt; Widgets

-   Footer widget: Donate

### Events Calendar

**Area**: Events

Events are managed through the WordPress plugin, Events Calendar\. Each event will have its own event post under the Events section\.

#### Key Elements for Events

-   Event Title
    -   The title to be displayed in the events calendar and events feed area
-   Time &amp; Date
    -   Start and end date and time of an event
    -   Only future events will be displayed in events feed, past events will only be visible on the calendar page

#### Event Highlights

-   For events to be listed under event highlights, select the following options:
    -   Category: Highlights
    -   Event Options: Feature Event, Sticky in Month View \(always visible\)
-   Event Highlights feed
    -   Homepage: Display three upcoming events with “Highlight” category
    -   Events page: Display six upcoming events with “Highlight” category

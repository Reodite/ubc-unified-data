The BIF has a wide variety of image processing and analysis software packages installed on two Windows workstations\.

One of the workstations is equipped with a pen\-tablet to select the regions of interest in the data\.

#### Available Software Packages:

**AMIRA**: Image processing and 3D modeling of TEM tomography, confocal, microCT, MRI, Dual Beam/Focused Ion Beam, and various other types of data

**Evident cellSens**: Confocal/light microscopy image processing and analysis

**Inspect 3D**: TEM tomography data reconstruction

**Dragonfly**: 3D data reconstruction of various types of data

**IMOD**: open source TEM tomography data reconstruction and basic modelling

**Fiji/ImageJ**: Open source scientific image processing/analysis

#### Cost:

Academic users: $13\.20/h, Industry users: $33/h

The Bioimaging team will assist you with your imaging project\. Of course, we need to know as much about your project as possible\.

If you are an academic user please download the project submission form, fill it out and send it to bif\.manager@ubc\.ca\.

If you are an industry user please visit [www\.imaginglabs\.ubc\.ca](http://imaginglabs.ubc.ca/) to download and fill out the external client agreement form found under “Working with us” before submitting any project information\.

If you would like an estimate of your project please use the link to the left and fill out the appropriate form\.

[Project submission form](https://bioimaging-2018.sites.olt.ubc.ca/files/2018/03/Project-submission-form.pdf)

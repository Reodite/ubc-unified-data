## [Animaker](https://woh.arts.ubc.ca/animaker/)

Animaker is a cloud\-based video animation software\. It allows users to create animated videos using pre\-built characters and templates\.

## [Powtoon](https://woh.arts.ubc.ca/powtoon/)

Powtoon helps create videos and presentations, and enhances videos with animation, stock footage, images, soundtracks, etc\.

## [Vyond](https://woh.arts.ubc.ca/vyond/)

Vyond creates, hosts and imports media that moves – characters, videos, MP4s, animated gifs\.

## [VideoScribe](https://woh.arts.ubc.ca/videoscribe/)

VideoScribe is a desktop\-based video creation platform specific to creating storyboarding/mind map type animated videos\.

## [Renderforest](https://woh.arts.ubc.ca/renderforest/)

Renderforest is an online tool used to create logos, intros, animations, slideshows, and other media components for branding\.

## [PlayPosit](https://woh.arts.ubc.ca/playposit/)

PlayPosit is a interactive video and assessment tool that lets users add interactive elements to existing streaming content on sites\.

## [OpenShot Video Editor](https://woh.arts.ubc.ca/openshot-video-editor/)

OpenShot is an open source desktop\-based video editor\.

## [Moovly](https://woh.arts.ubc.ca/moovly/)

Moovly is a cloud\-based platform that generates multimedia content including animated videos, presentations, and infographics\.

## [Camtasia](https://woh.arts.ubc.ca/camtasia/)

Camtasia allows the user to create video presentations by capturing content on\-screen and editing through the built\-in editing tool\.

## [Adobe Express](https://woh.arts.ubc.ca/adobe-spark/)

Adobe Spark is a free online graphic design and video creation application, that is also offered in a paid version with greater benefits\.

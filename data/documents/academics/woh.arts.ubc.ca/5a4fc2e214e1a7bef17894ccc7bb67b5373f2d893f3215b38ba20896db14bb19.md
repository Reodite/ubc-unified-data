StoryMapJS is a free web\-based storytelling tool that highlights the locations of a series of events through a map, and an accompanying popup slideshow\.

#### Notable Features

-   A rare free mapping software
-   Offers the ability to create maps on existing web maps, as well as maps using historical/fantasy/general images

#### Limitations

-   Can be glitchy
-   Lacks customization options for fonts
-   Requires large size images \(gigapixel\) for historical/other map creation
-   Limited tutorials for new users beyond user guides and examples

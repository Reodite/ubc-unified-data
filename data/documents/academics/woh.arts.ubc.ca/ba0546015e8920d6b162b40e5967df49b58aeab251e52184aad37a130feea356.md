Omeka is a free, open source web publishing system for online digital archives that is available in an online as well as desktop application\.

#### Notable Features

-   Web interface and back\-end cataloguing system are one unified application
-   Offers templates and page layouts without having to code \(though users with coding skills can use code to make more complex layouts through customization\)\.

#### Limitations

-   Learning curve is a challenge since this requires significant familiarization with the interface and some technical understanding of metadata, \.CSV file formats, etc\.

[Embedded iframe \(view source\)](https://www.youtube.com/embed/B70J_H_zAWM)OpenRefine \(formerly Google Refine\) is a tool for working with messy data: cleaning it; transforming it from one format into another; and extending it with web services and external data\.

#### Notable Features

-   OpenRefine can connect databases to different web services\.

#### Limitations

-   Older interface makes it more difficult to work with\.

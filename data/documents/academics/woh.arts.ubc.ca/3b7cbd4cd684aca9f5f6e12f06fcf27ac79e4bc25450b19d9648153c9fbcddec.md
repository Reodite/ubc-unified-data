## [Squarespace](https://woh.arts.ubc.ca/squarespace/)

SquareSpace is a popular, online website building applications that builds websites through an accessible user interface\.

## [Second Life](https://woh.arts.ubc.ca/second-life/)

Second Life is a platform that allows users to create virtual realities that are accessible to other users globally\.

## [Renderforest](https://woh.arts.ubc.ca/renderforest/)

Renderforest is an online tool used to create logos, intros, animations, slideshows, and other media components for branding\.

## [Prezi](https://woh.arts.ubc.ca/prezi/)

Prezi is an online based tool for creating engaging presentations\.

## [PressBooks](https://woh.arts.ubc.ca/pressbooks/)

PressBooks is an online publishing tool for creating books that operates off the WordPress blogging platform\.

## [PowerPoint](https://woh.arts.ubc.ca/powerpoint/)

MS PowerPoint is the industry standard for creating presentations, and is part of the MS Office Suite of applications\.

## [PlayPosit](https://woh.arts.ubc.ca/playposit/)

PlayPosit is a interactive video and assessment tool that lets users add interactive elements to existing streaming content on sites\.

## [OpenShot Video Editor](https://woh.arts.ubc.ca/openshot-video-editor/)

OpenShot is an open source desktop\-based video editor\.

## [Omeka](https://woh.arts.ubc.ca/omeka/)

Omeka is a free, open source web publishing system for online digital archives\.

## [Moovly](https://woh.arts.ubc.ca/moovly/)

Moovly is a cloud\-based platform that generates multimedia content including animated videos, presentations, and infographics\.

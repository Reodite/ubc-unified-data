[Embedded iframe \(view source\)](https://www.youtube.com/embed/8vD9Mciquhs)Renderforest is an online tool used to create logos, intros, animations, slideshows, and other media components for branding purposes\.

#### Notable Features

-   Fast rendering
-   Good templates offered
-   Accessible user interface
-   Ability to make changes while editing

#### Limitations

-   Free version limited to videos of up to 3 min
-   Watermarks on all files
-   Video quality restricted to mostly 360p

Inkscape is a vector graphics editor similar to Adobe Illustrator\.

#### Notable Features

-   Cross\-platform; runs easily on different operating systems
-   Uses Scalable Vector Graphics \(SVG\)

#### Limitations

-   Tutorials are only accessible via desktop uploading, and not online where they are read\-only

## [Tinkercad](https://woh.arts.ubc.ca/tinkercad/)

Tinkercad is an application for 3D design, electronics, and coding\.

## [Crello](https://woh.arts.ubc.ca/crello/)

Crello is a visual editor that creates social media images, ad banners, posters, email headers, and other popular formats\.

## [Vectr](https://woh.arts.ubc.ca/vectr/)

Vectr is a free graphic design software used to create vector graphics using mathematical equations to draw a design\.

## [GitHub](https://woh.arts.ubc.ca/github/)

GITHUB supports code reviewing, project management, integration, team management, social coding, documentation, and code hosting\.

## [WordPress](https://woh.arts.ubc.ca/wordpress/)

WordPress is a website building application\. The user can edit websites through an accessible user interface or through coding\.

## [Wix](https://woh.arts.ubc.ca/wix/)

Wix is one of many free, online website building applications, and builds websites through an accessible user interface\.

## [Weebly](https://woh.arts.ubc.ca/weebly/)

Weebly is a website building application that allows websites to be created through an accessible user interface instead of coding\.

## [VideoScribe](https://woh.arts.ubc.ca/videoscribe/)

VideoScribe is a desktop\-based video creation platform specific to creating storyboarding/mind map type animated videos\.

## [TimelineJS](https://woh.arts.ubc.ca/timelinejs/)

TimelineJS is a free web\-based storytelling tool that highlights the time period of a series of events through a timeline\.

## [StoryMapJS](https://woh.arts.ubc.ca/storymapjs/)

StoryMapJS is a free web\-based storytelling tool that highlights the locations of a series of events through a map\.

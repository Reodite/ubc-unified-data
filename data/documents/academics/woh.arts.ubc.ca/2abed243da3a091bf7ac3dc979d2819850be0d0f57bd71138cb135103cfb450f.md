## [Venngage](https://woh.arts.ubc.ca/venngage/)

Venngage is a web\-based graphic design tool that offers ease of access for creating professional high\-quality infographics\.

## [Infogram](https://woh.arts.ubc.ca/infogram/)

Infogram is a data visualization and infographics platform for making and sharing digital charts, infographics and maps\.

## [Animaker](https://woh.arts.ubc.ca/animaker/)

Animaker is a cloud\-based video animation software\. It allows users to create animated videos using pre\-built characters and templates\.

## [Figma](https://woh.arts.ubc.ca/figma/)

Figma is an interface design application for creating prototypes and gathering feedback through vector tools and code generation\.

## [Powtoon](https://woh.arts.ubc.ca/powtoon/)

Powtoon helps create videos and presentations, and enhances videos with animation, stock footage, images, soundtracks, etc\.

## [Vyond](https://woh.arts.ubc.ca/vyond/)

Vyond creates, hosts and imports media that moves – characters, videos, MP4s, animated gifs\.

## [Tableau Public](https://woh.arts.ubc.ca/tableau-public/)

Tableau Public creates and shares interactive charts, graphs, maps, and live dashboards that are publicly publishable\.

## [OpenRefine](https://woh.arts.ubc.ca/openrefine/)

OpenRefine is a tool for cleaning mess data, transforming it between formats, and extending it with web services and external data\.

## [Inkscape](https://woh.arts.ubc.ca/inkscape/)

Inkscape is a vector graphics editor similar to Adobe Illustrator\.

## [GIMP](https://woh.arts.ubc.ca/gimp/)

GIMP is a cross\-platform image editor available in different operating systems\.

[Embedded iframe \(view source\)](https://www.youtube.com/embed/9rR5PpHSoIQ)Weebly is one of many free, online website building applications that operates in a dashboard format\. The user is offered the ability to edit websites through an accessible user interface, instead of coding, though the latter option is also offered\.

#### Notable Features

-   Designed specifically for non\-tech\-savvy users
-   Useful for designing simple websites
-   Offers a drag\-and\-draop editor

#### Limitations

-   Building complex websites \(beyond simple portfolio showcase websites, for example\) can be a challenge and often necessitates pre\-existing technical knowledge\.

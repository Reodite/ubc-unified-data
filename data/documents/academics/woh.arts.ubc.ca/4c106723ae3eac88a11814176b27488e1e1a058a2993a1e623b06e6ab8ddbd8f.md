[Embedded iframe \(view source\)](https://www.youtube.com/embed/Cx2dkpBxst8)Figma is an interface design application that allows users to create prototypes and gather feedback by providing vector tools and code generation\. \(UI design, UX design, prototyping, graphic design, wireframing, brainstorming, templates\)

#### Notable Features

-   Allows users to create and share reusable components and styles with teams
-   Gives developers the ability to inspect, copy, export assets, and copy CSS directly from the design file
-   Works 100% on the user’s browser and desktop

#### Limitations

-   Requires the user to log in
-   Lacks advanced prototype features

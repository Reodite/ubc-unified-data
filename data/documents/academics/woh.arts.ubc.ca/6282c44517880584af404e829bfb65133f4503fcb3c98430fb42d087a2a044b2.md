## [H5P](https://woh.arts.ubc.ca/h5p/)

H5P is an application for creating and integrating HTML5 interactive content into desktop and web publishing platforms\.

## [Drupal](https://woh.arts.ubc.ca/drupal/)

Drupal is one of many free website building applications that allows users to edit websites through an accessible user interface\.

## [Canva](https://woh.arts.ubc.ca/canva/)

Canva is a web\-based graphic design tool that offers ease of access for creating professional high\-quality graphics\.

## [Camtasia](https://woh.arts.ubc.ca/camtasia/)

Camtasia allows the user to create video presentations by capturing content on\-screen and editing through the built\-in editing tool\.

## [BookWright](https://woh.arts.ubc.ca/bookwright/)

BookWright is a desktop\-based publishing application designed for creating ebooks with professional layouts\.

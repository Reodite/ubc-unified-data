Course ID DSCI 513

Campus UBC Vancouver

Semester Fall

Course Block 3

Course Description Learn how to work with data stored in relational and NoSQL database systems\. Learn SQL through Data Definition Language \(DDL\) to create schemas, define keys, and enforce integrity constraints, and Data Manipulation Language \(DML\) to query, join, and aggregate data\. Get introduced to various NoSQL databases, focusing on document databases, specifically MongoDB, and querying with the MongoDB Query Language \(MQL\)\.

Course ID DATA 582

Campus UBC Okanagan

Semester Winter

Course Block 6

Course Description Introduction to Bayesian paradigm and tools for Data Science\. Topics include Bayes theorem, prior, likelihood and posterior\. A detailed analysis of the cases of binomial, normal samples, normal linear regression models\. A significant focus will be on computational aspects of Bayesian problems using software packages\.

Course ID DSCI 525

Campus UBC Vancouver

Semester Winter

Course Block 5

Course Description Go beyond the limits of your laptop and learn to tackle large\-scale data science tasks\. You will build and automate scalable data pipelines and access cloud resources via Web APIs, leverage cloud platforms for distributed machine learning with Spark, and deploy your models into production environments\.

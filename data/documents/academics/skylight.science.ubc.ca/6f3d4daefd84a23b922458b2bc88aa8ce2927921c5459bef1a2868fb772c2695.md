This page summarizes the different features available in Zoom meetings and Zoom webinars \. Learn more about [the differences between Zoom meetings and webinars](https://support.zoom.com/hc/en/article?id=zm_kb&amp;sysparm_article=KB0062404)\. 

For a detailed guide of how to use Zoom, please refer to our [Zoom user guide\.](https://skylight.science.ubc.ca/lt/guides/zoom) 

### Features

- **Row 1**

  - **Cell 1:**
  
    (empty)
  
  - **Cell 2:**
  
    **Meetings**
  
  - **Cell 3:**
  
    **Webinars**

- **Row 2**

  - **Cell 1:**
  
    **Description**
  
  - **Cell 2:**
  
    Ideal for hosting interactive meetings with audience participation or breaking into smaller groups
  
  - **Cell 3:**
  
    Similar to virtual lectures, webinars are suitable for a large audience, or events open to the public where there is limited participant interaction and only a few speakers

- **Row 3**

  - **Cell 1:**
  
    **Group Size**
  
  - **Cell 2:**
  
    -   Up to 300 participants 
    -   Up to 1000 participants if your account has a large meeting add\-on
  
  - **Cell 3:**
  
    -   300\-1000 participants \(*submit request to* [*av\.helpdesk@ubc\.ca*](mailto:av.helpdesk@ubc.ca)\)

- **Row 4**

  - **Cell 1:**
  
    **Roles**
  
  - **Cell 2:**
  
    -   Host \(can only have one host per session\) 
    -   Co\-host 
    -   Participant
  
  - **Cell 3:**
  
    -   Host \(can only have one host per session\) 
    -   Co\-host 
    -   Panelist 
    -   Attendee

- **Row 5**

  - **Cell 1:**
  
    **Access to create meetings**
  
  - **Cell 2:**
  
    -   Instructors, TAs, Course Assistants, Course Facilitators in the course with a [UBC Zoom account](https://skylight.science.ubc.ca/lt/guides/zoom#getting-started)
  
  - **Cell 3:**
  
    -   UBC Audio Visual Services [\(av\.helpdesk@ubc\.ca\)](mailto:av.helpdesk@ubc.ca)

- **Row 6**

  - **Cell 1:**
  
    **Breakout Groups/Rooms**
  
  - **Cell 2:**
  
    -   Maximum 100 breakout rooms \(**Note**: Same limitations apply for accounts with the large meeting add\-on\) 
    -   The h ost can:  
        -   Set a timer to notify participants in the breakout rooms on time remaining 
        -   Broadcast messages to all breakout rooms 
        -   Screen share to all breakout rooms 
    -   Participants can click on the "Ask for help" button to get the host's attention 
    -   Both the host and co\-hosts can create/manage self\-select, manual, and automatic breakout rooms; however, only the host can create pre\-assigned breakout rooms 
    -   Learn more about [managing breakout rooms in meetings](https://support.zoom.com/hc/en/article?id=zm_kb&amp;sysparm_article=KB0062540)
  
  - **Cell 3:**
  
    -   Maximum 200 breakout rooms  
    -   **Note**: Unlike meeting breakout rooms, both the host and any co\-hosts can assign participants to breakout rooms, without overriding the other’s changes

- **Row 7**

  - **Cell 1:**
  
    **Polling**
  
  - **Cell 2 (colspan 2; rowspan 1):**
  
    -   Polls are created in the Zoom web interface outside of the meeting by the host in advance or on the fly\. The original meeting host can edit or add additional poll questions during the meeting\. If the meeting is scheduled via the Zoom web interface, the original meeting host can enable the setting to allow alternate hosts to also add or edit polls \(available for Zoom version &gt;5\.15\.0\) 
    -   The host can create advanced polls and quizzes that include a greater variety of question types\. Learn more about [advanced polling and quizzing](https://support.zoom.us/hc/en-us/articles/4412325214477-Advanced-polling-and-quizzing-for-meetings) 
    -   Poll results are saved, but not tied to student IDs 
    -   **Note**: Participants who join through the browser cannot participate in polling; they must join using the desktop application or mobile app\. The host can only manage polls using the desktop application 
    -   Learn more about [how to create polls in Zoom](https://skylight.science.ubc.ca/lt/guides/zoom#set-up-zoom-polls) and [polling in meetings](https://support.zoom.us/hc/en-us/articles/213756303-Polling-for-meetings) 
    -   Learn more about [polling in webinars](https://support.zoom.com/hc/en/article?id=zm_kb&amp;sysparm_article=KB0066668)

- **Row 8**

  - **Cell 1:**
  
    **Audio Sharing**
  
  - **Cell 2:**
  
    -   All participants can mute/unmute their own audio 
    -   Host can mute/request to unmute participants 
    -   Host can set all participants to mute upon entry
  
  - **Cell 3:**
  
    -   Only host and panelist\(s\) can mute/unmute their audio 
    -   Attendees join in listen\-only mode 
    -   Only the host can unmute attendees

- **Row 9**

  - **Cell 1:**
  
    **Video Sharing**
  
  - **Cell 2:**
  
    -   All participants
  
  - **Cell 3:**
  
    -   Host and panelist\(s\) only

- **Row 10**

  - **Cell 1:**
  
    **Max videos on screen**
  
  - **Cell 2 (colspan 2; rowspan 1):**
  
    -   Up to 25 videos per page [using gallery view](https://support.zoom.com/hc/en/article?id=zm_kb&amp;sysparm_article=KB0068420#:~:text=Gallery%20View%20displays%20up%20to,if%20enabled%20in%20the%20settings) \(more videos can be shown on additional pages\)

- **Row 11**

  - **Cell 1:**
  
    **Chat**
  
  - **Cell 2:**
  
    -   Host can disable chat for attendees, allow them to chat with the host only, everyone publicly or everyone publicly and privately 
    -   Chat can be set to save automatically \(all public chat messages plus any private messages sent or received by the person saving\), or can be saved on the fly 
    -   Learn more about [in\-meeting chat](https://support.zoom.us/hc/en-us/articles/203650445-In-Meeting-Chat)
  
  - **Cell 3:**
  
    -   Host can disable chat for attendees, allow them to chat with all panelists \(including host\), or with all panelists and attendees 
    -   \*[Question &amp; Answer](https://support.zoom.us/hc/en-us/articles/203686015-Getting-Started-with-Question-Answer) option can be used as an alternative 
    -   Learn more about [webinar chat](https://support.zoom.us/hc/en-us/articles/205761999-Using-webinar-chat)

- **Row 12**

  - **Cell 1:**
  
    **Interactive tools**
  
  - **Cell 2:**
  
    -   Whiteboard, share screen, file sharing, annotations, raise hand, reaction buttons
  
  - **Cell 3:**
  
    -   Whiteboard, share screen, annotations, [raise hand](https://support.zoom.us/hc/en-us/articles/205566129), [Q&amp;A](https://support.zoom.us/hc/en-us/articles/203686015-Getting-Started-with-Question-Answer)

- **Row 13**

  - **Cell 1:**
  
    **Recordings**
  
  - **Cell 2 (colspan 2; rowspan 1):**
  
    -   Sessions can be recorded locally or to the cloud 
    -   Local recordings will be downloaded to the host's computer after the meeting 
    -   Cloud recordings can be accessed in Canvas through the Zoom link \(including the ability to download\), once published 
    -   Public chat messages to everyone are recorded 
    -   Polls are not recorded 
    -   Learn more about [Zoom recordings](https://skylight.science.ubc.ca/lt/guides/zoom#download-zoom-recordings)

- **Row 14**

  - **Cell 1:**
  
    **Tracking attendance**
  
  - **Cell 2 (colspan 2; rowspan 1):**
  
    -   Attendance reports can be downloaded through the [web portal](https://zoom.us/signin)\. The report will show who attended, join time, leave time, and the duration they were in the meeting 
    -   Students' name \(as listed in Canvas\) will appear in the report as long as they joined the meeting through Canvas using the desktop application, not through the web browser 
    -   Learn more about [meeting reports](https://support.zoom.us/hc/en-us/articles/216378603-Generating-Meeting-Reports-for-Registration-and-Polling) and [attendance reports](https://support.zoom.com/hc/en/article?id=zm_kb&amp;sysparm_article=KB0073594)

- **Row 15**

  - **Cell 1:**
  
    **Accessibility**
  
  - **Cell 2 (colspan 2; rowspan 1):**
  
    -   Closed captioning, audio transcription, Screen Reader Support, Keyboard accessibility/shortcuts 
    -   Learn more about [accessibility](https://zoom.us/accessibility)\.

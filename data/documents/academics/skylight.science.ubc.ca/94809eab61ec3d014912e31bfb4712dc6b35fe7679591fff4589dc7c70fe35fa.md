Turnitin is a plagiarism\-prevention tool to determine and check the originality and academic integrity of student submissions\. It generates a report \(the similarity report\) by comparing student submissions to its vast database of web pages, previous student submissions, and thousands of periodicals, journals, and publications\. Turnitin can be used in Canvas by creating an assignment and enabling plagiarism review\.  

### Key Features

-   **Identify plagiarism**: compare student work to Turnitin’s vast database to identify similarities
-   **Check citations**: identify improper citations in students’ work  

### Getting Started

After your Canvas course is created, you can create Turnitin assignments in Canvas\.  

However, if you would like to use Turnitin as a standalone, please email Science LT at [LT\.support@science\.ubc\.ca](mailto:LT.support@science.ubc.ca) to request a Turnitin account\.

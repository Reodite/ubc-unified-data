1.  Read the following sentence and decide which option places \(or does not place\) hyphens correctly in it: **Science\-minded students** from the University of British Columbia run the program\. \(***There should be a hyphen where it is here because ‘science\-minded’ is a compound word\.***
    
2.  Read the following sentence and decide which option places \(or does not place\) apostrophes correctly in it:  **Sarah’s pet dogs** are all very friendly\. \(***There should be an apostrophe where it is because Sarah owns the dogs***\)\.
3.  Read the following sentence and decide which grammar mechanic is **incorrectly** used: By using the Floral Powerset**’**s data**,** like minded**–**researchers can probe important ecological questions without ever conducting fieldwork themselves\.

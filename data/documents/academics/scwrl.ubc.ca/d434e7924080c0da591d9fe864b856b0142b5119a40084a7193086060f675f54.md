**1\)** Read the following sentence and select the correct style for the number in it:

**Fifty** years ago, the Earth’s rainforests were in a much better state\. \(*You should not start a sentence with a numeral, which is why 50 is incorrect here*\)

**2\)** Read the following sentence and select the correct style for the number in it:

Now, due to deforestation, experts predict that up to **50,000** species go extinct each year\.

\(*You should use numerals for numbers over 9, and split larger numbers up with commas to make them easier to interpret*\)

**3\)** Read the following sentence and select the correct style for the number and unit in it:

This means that **25%** of all species might be gone by 2065\.

\(*You should use numerals when talking about ‘per cent’ measurements, and not include a gap between the numeral and the unit*\)

**4\)** Read the following sentence and select the correct style for the number and unit in it:

As a measure of how rapidly forests can be lost, logging in Amazonian Brazil rose by **69%** in just 12 months, between 2007 and 2008\. \(*You should use numerals when talking about ‘per cent’ measurements, and not include a gap between the numeral and the unit*\)

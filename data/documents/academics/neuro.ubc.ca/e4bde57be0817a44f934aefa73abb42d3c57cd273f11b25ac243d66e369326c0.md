The Undergraduate Program in Neuroscience offices are in UBC Hospital Koerner F170\. Here’s a link to a [campus map showing the building location](https://maps.ubc.ca/?code=KPAV)\.

If you enter from the Main Entrance or the South Entrance \(marked with green arrows below\), you will be on the Main Floor of the hospital\. The program offices are on the First Floor \(one floor up from the Main Floor\)\. Use the south elevators \(outside Student Health Services\) and go up one floor – from there you will see signs for the Undergraduate Program in Neuroscience\.

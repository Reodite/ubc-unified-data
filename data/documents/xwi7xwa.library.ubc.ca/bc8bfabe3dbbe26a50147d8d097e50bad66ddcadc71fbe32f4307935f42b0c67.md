Are you a student at the UBC School of Information? We’re hiring for the following positions \(10 hrs/wk\):

-   ID : 889979   Indigenous Public Services Student Librarian
-   ID : 889981   Indigenous Technical Services Student Librarian
-   ID : 889974   Xwi7xwa Archives Curation &amp; Digitization Assistant

Process to access the Job Descriptions \(JD\) and apply:

1.  Start here, please read the important message about Job Scams: [https://students\.ubc\.ca/career/career\-resources/job\-posting\-scams](https://students.ubc.ca/career/career-resources/job-posting-scams)
2.  Click the button: ‘Careers Online’
3.  Login with you Campus Wide Login \(CWL\); [not sure what this is? See here for assistance](https://it.ubc.ca/services/accounts-passwords/campus-wide-login-cwl)
4.  Authenticate using UBC’s Enhanced CWL Duo Mobile App or Token; [not sure what this is? see here for assistance](https://privacymatters.ubc.ca/learn-about-enhancedcwl)
5.  Search: ***Xwi7xwa*** or the ***ID*** of desired position \(see above\)

If you have any questions please do not hesitate to email: [tamis\.cochrane@ubc\.ca](mailto:tamis.cochrane@ubc.ca)

**SimHERA Case Database**

SimHERA’s “Public” Case Database can be accessed via this link:

[https://drive\.google\.com/drive/folders/1mdERVrsN\_qXz5JdiJ1p77ZegXeMHdneO?usp\=sharing](https://drive.google.com/drive/folders/1mdERVrsN_qXz5JdiJ1p77ZegXeMHdneO?usp=sharing)

You may download and upload cases from this Database\. Please make sure that cases you create are truly simulated cases and have no identifiable information within them if you base your case on a real patient\.

Please do NOT overwrite the cases that are already in the database\. If you would like to make changes to a case, then duplicate it and save it as another case ID\.

Please act responsibly because this is an open “Public” database\.

For access to the “instructor” database, please contact Dr\. Tony Herdman: aherdman@audiospeech\.ubc\.ca

Some cases within the database are provided on the tabs to the right with corresponding Tutorial videos\.

**Lexique Pro — Introduction**

> “Lexique Pro is all about making your data usable, accessible, and easy to share with others\. And not only that…you may find you use it more yourself\!”
> 
>   
> *[Lexique Pro SIL Website](https://software.sil.org/lexiquepro/)*

[https://dictionaries\.sites\.olt\.ubc\.ca/files/2023/05/Lexique\-Pro\-Logo\.png](https://dictionaries.sites.olt.ubc.ca/files/2023/05/Lexique-Pro-Logo.png)[Image](https://dictionaries.sites.olt.ubc.ca/files/2023/05/Lexique-Pro-Logo.png)

Lexique Pro Logo

**Lexique Pro is an interactive lexicon viewer and editor designed to share and disseminate dictionary data\.** While Lexique Pro is intended to be used with existing, not yet\-user\-friendly lexicons, it can also compile a new lexicon\. Lexique Pro integrates easily with other SIL software, such as [Toolbox](https://dictionaries.sites.olt.ubc.ca/toolbox/), [FLEx](https://dictionaries.sites.olt.ubc.ca/fieldworks-language-explorer-flex/), and [WeSay](https://dictionaries.sites.olt.ubc.ca/wesay/)\. In addition, Lexique Pro can be used to add a search function to a database, connect related entries with hyperlinks, and group semantic categories\. It also supports the inclusion of images and audio in entries\. 

This software assumes some background knowledge in lexicography and moderate computer skills\. **Lexique Pro is only available for computers using Windows** **operating systems**\. 

The final product of Lexique Pro is a dictionary that can either be downloaded, uploaded to a website, or printed \(although a printed dictionary will not have any multimedia or interactive features\)\. 

Lexique Pro has not been updated since August 2012, so it is somewhat outdated\. On their website, the developer, [SIL International](https://software.sil.org/about/#about), states they no longer support Lexique Pro\. Instead, SIL recommends publishing electronic dictionaries and grammars through [Webonary](https://www.webonary.org/)\.

## Highlights

-   Free software
-   The final product can be downloaded, uploaded online, or printed
-   Well integrated with [Toolbox](https://dictionaries.sites.olt.ubc.ca/toolbox/), [FLEx](https://dictionaries.sites.olt.ubc.ca/fieldworks-language-explorer-flex/), and [WeSay](https://dictionaries.sites.olt.ubc.ca/wesay/)
-   Unicode compliant

-   Easy to share resources with collaborators
-   Many functions automated
-   Supports diacritics
-   Can apply changes to the entire database at once
-   Straightforward database installation

## Considerations

-   Has not been updated since 2012
-   Is no longer supported by SIL International
-   Limited options for customization
-   Requires background knowledge of lexical field markers
-   Only available for Windows operating systems
-   The downloaded version of a Lexique Pro lexicon cannot be opened easily on MacOS or Linux

-   Images do not always transfer properly when exporting to TXT or HTML files
-   Some bugginess in the search function
-   Export categories are not customizable

## Alternatives to Lexique Pro

---

[Language Forge](https://knowledgebase.arts.ubc.ca/language-forge/) is comparable to Lexique Pro, in that it adds more functionality to a database compiled using SIL software\. Language Forge, however, is updated more regularly and is compatible with macOS\.

## **Examples of Dictionaries Using Lexique Pro**

---

An example of a Bambara to French dictionary created with Lexique Pro can be found [here](http://www.bambara.org/en/index.htm)\.

## **Support Services**

---

On the Lexique Pro website, there is a [user guide](https://software.sil.org/downloads/r/lexiquepro/Lexique%20Pro%20-%20User%20Guide%202.5.pdf), and a [FAQ page](https://software.sil.org/lexiquepro/support/faq/)\.

SIL International no longer offers direct support for Lexique Pro, and instead directs users to visit the [SIL Language Software Community](https://community.software.sil.org/) online forum\.

## Developer

---

Lexique Pro was developed by SIL International in 2004\. The newest version of the software \(version 3\.6\) dates to 2012\. This software is no longer being updated\.

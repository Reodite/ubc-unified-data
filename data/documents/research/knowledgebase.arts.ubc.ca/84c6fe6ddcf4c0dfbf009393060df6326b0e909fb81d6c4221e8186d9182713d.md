## Instructions/Manuals/Guides

[**1\. YouTube Tutorial**](https://www.youtube.com/watch?v=cBTRMxWGgbQ)

**Resource Type:** Video

Gtryus\. “PathwayDemo\.” *YouTube*\. [https://www\.youtube\.com/watch?v\=cBTRMxWGgbQ](https://www.youtube.com/watch?v=cBTRMxWGgbQ)\. Accessed May 25, 2022\.

---

This YouTube video provides an overview of Pathway and details how to complete each step needed to publish a dictionary online or in print\.

It is a helpful starting point for those who are interested in learning more about Pathway, as it explains how the software works and where to find it\.

This video can be found [here](https://www.youtube.com/watch?v=cBTRMxWGgbQ)\.

[**2\. User Guide**](https://software.sil.org/pathway/resources/tutorial/getting-started/)

**Resource Type:** Website

SIL International\. “Getting Started\.” *Pathway Project*\. [https://software\.sil\.org/pathway/resources/tutorial/getting\-started/](https://software.sil.org/pathway/resources/tutorial/getting-started/)\. Accessed May 25, 2022\.

---

This page from the Pathway website details how to begin using Pathway\. It describes how to open the plug\-in in [FLEx](https://dictionaries.sites.olt.ubc.ca/fieldworks-language-explorer-flex/) and Paratext and the basic steps for exporting data\. This page also has short descriptions of each function\.

Users looking for a brief how\-to while setting up Pathway may find this resource helpful\.

This user guide can be found [here](https://software.sil.org/pathway/resources/tutorial/getting-started/)\.

[**3\. Resources Page**](https://software.sil.org/pathway/resources/)

**Resource Type:** Website

SIL International\. “Resources\.” *Pathway Project*\. [https://software\.sil\.org/pathway/resources](https://software.sil.org/pathway/resources)\. Accessed May 25, 2022\.

---

This resources page on the Pathway website includes multiple pages which detail how to complete specific tasks in Pathway\. These topics include how to edit photographs, adjust a table of contents, and how to install the software\.

It is a helpful place for users struggling with a specific issue\.

This page can be found [here](https://software.sil.org/pathway/resources/)\.

Cheyenne Picture Dictionary

## Language Name

Cheyenne\.

## Alternate Language Names

Tsėhésenėstsestȯtse\.

## Region

Montana and Oklahoma, United States\.

## Who

Chief Dull Knife College\.

## Others Involved

There is no information included in the in the web version or downloadable Word file about others involved in the creation of this dictionary\.

## Publishing Information

This is a digital dictionary that does not display information about launch dates or update dates\. An earlier version of this dictionary in the format of a free, downloadable Word document is linked on the Cheyenne Language website\. It was published in 2004 by Chief Dull Knife College\. A print edition was published by Chief Dull Knife College in 2009\.

## How People are Cited

This dictionary does not cite any authors or contributors in the web version or downloadable Word file\.

## How Information is Cited

Neither the web version nor the downloadable Word file cites the source of any of its information\.

## Where is Information Coming from

The web version and downloadable Word file do not indicate where information is coming from or what sources were used\.

## Tools and Framework used

This dictionary is available as a multimedia website \(using images and audio\), as a Microsoft Word document using text and images, and as a physical book that uses images and text\.

## Access

The web dictionary is open access online\. The Word file is available as an open access download on the Cheyenne Language website\. The physical book is available for purchase for $16\.99 USD on Lulu\.com\.

## Included Languages and Directionality

English category headers with picture entries and Cheyenne audio \(website\)\. In the Word document and the print dictionary, pictures are accompanied by the Cheyenne word in print\.

## Dialects Included

No dialect is specified for the web version or downloadable Word file\.

## Type of Dictionary

This is a monolingual, topical picture dictionary\.

## How are Entries Organised

Entries in the web version of this dictionary are organised by topics\. Topics are organised alphabetically and are written in English\. Within each topic, each entry is listed as an image and embedded audio recording of the corresponding Cheyenne word\. To hear the audio, click on the image\. There is no written Cheyenne in this version of the dictionary\.

Entries in the 2004 Word document are organised by topics including animals, appearance, numbers, etc\. Each entry shows a photograph and the Cheyenne word\. No other information is included in entries\.

We are unable to access the print dictionary to determine how entries are organised\. According to the description on Lulu\.com, it is a picture book where each picture is accompanied by a Cheyenne word\.

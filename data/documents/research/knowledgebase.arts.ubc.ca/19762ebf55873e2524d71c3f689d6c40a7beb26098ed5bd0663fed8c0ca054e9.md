## ****Instructions/Manuals/Guides****

[**1\. Self\-Paced Guides**](http://www.fieldlinguiststoolbox.org/)

**Resource Type:** Downloadable Guide

“Downloads &amp; Documentation\.” *Field Linguist’s Toolbox\.* [http://www\.fieldlinguiststoolbox\.org/](http://www.fieldlinguiststoolbox.org/)\. Accessed April 24, 2022\.

---

The Toolbox *Download Page* offers a variety of self\-paced guides and exercises to introduce users to the software\. The guides are available as downloadable PDFs\. The guides cover specific steps, such as how to interlinearlize text, manage ZIP files, handle tone, and more\. This page also has files to start a new project and practice examples to support learning\.

These files are helpful guides for those starting with Toolbox, while offering a more comprehensive understanding of specific Toolbox features that users may otherwise struggle with\.

The self\-paced guides can be found [here](http://www.fieldlinguiststoolbox.org/)\.

[**2\. Support**](https://software.sil.org/toolbox/support/)

**Resource Type:** Website

SIL International\. “Support\.” *Field Linguist’s Toolbox*\. [https://software\.sil\.org/toolbox/support/](https://software.sil.org/toolbox/support/)\. Accessed April 24, 2022\.

---

The SIL International Toolbox website has a support page with a form where users are able to ask questions, report bugs in the program, or make recommendations\. This is free to use\. Additionally, the Toolbox Website lists an email address \(*toolbox@sil\.org*\) to which users can send questions about the software\.

The support page can be found [here](https://software.sil.org/toolbox/support/)\.

[**3\. Training Guide**](http://www.ling.helsinki.fi/kit/2009k/clt234/docs/Toolbox_Self-Training.pdf)

**Resource Type:** Downloadable Guide

Buseman, A\. and Buseman, K\. 2007\. *Toolbox Self\-Training: How to use the Field Linguist’s Toolbox\.* [http://www\.ling\.helsinki\.fi/kit/2009k/clt234/docs/Toolbox\_Self\-Training\.](http://www.ling.helsinki.fi/kit/2009k/clt234/docs/Toolbox_Self-Training.pdf)[pdf](http://www.ling.helsinki.fi/kit/2009k/clt234/docs/Toolbox_Self-Training.pdf)\.

---

This 126\-page training guide for Toolbox details all the information needed to begin using the software\. This document walks users through downloading Toolbox, provides an introduction to the software, an overview of the steps needed to create a dictionary, and includes information on how to perform more complicated commands\.

This guide is a helpful starting point for those new to Toolbox, while offering a more comprehensive understanding of all of the features Toolbox offers\.

The training guide can be found [here](http://www.ling.helsinki.fi/kit/2009k/clt234/docs/Toolbox_Self-Training.pdf)\.

## Managing Fieldwork Data with Toolbox and the Natural Language Toolkit

*Abstract:*

“This paper shows how fieldwork data can be managed using the program Toolbox together with the Natural Language Toolkit \(NLTK\) for the Python programming language\. It provides background information about Toolbox and describes how it can be downloaded and installed\. The basic functionality of the program for lexicons and texts is described, and its strengths and weaknesses are reviewed\. Its underlying data format is briefly discussed, and Toolbox processing capabilities of NLTK are introduced, showing ways in which it can be used to extend the functionality of Toolbox\. This is illustrated with a few simple scripts that demonstrate basic data management tasks relevant to language documentation, such as printing out the contents of a lexicon as HTML\.”

This article can be found [here](http://hdl.handle.net/10125/1725)\.

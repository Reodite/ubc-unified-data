## Access

## 1\. Access &amp; Compatibility

---

KirrKirr is available for download on **Windows**, **Linux**, and **MacOS** 10\.4 or above\. In order to download the software, Java needs to be installed\. The software can be downloaded from the [Downloads and Shipping section](https://nlp.stanford.edu/kirrkirr/#Download) of the KirKirr website\.

## 2\. Cost

---

This is a **free** tool\. However, Kirrkirr is not open source, and specific information about the ownership and license limits of the software are not detailed\.

All screenshots explaining features on the Kirrkirr website are property of its traditional owners\. They cannot be reproduced or distributed without permission\.

## 3\. Internet

---

**Internet access is required** to use Kirrkirr\.

## 4\. Skills Required

---

**To add a dictionary to Kirrkirr, experience with XML and XSLT is needed**, as there can be issues with importing data depending on the original format of the dictionary\. Once a user imports language data into the software, Kirrkirr’s many features are automatically applied and ready for use\. A completed, robust XML dictionary must be imported to Kirrkirr in order to use the software\.

Once a dictionary file is successfully uploaded to Kirrkirr, **only basic computer skills are required to interact with Kirrkirr**\. The process of creating games, adding semantic maps, and setting up a search function is mostly automated\.

Some visualizations created by Kirrkirr can be confusing to users of the final product without a linguistic background\. Semantic maps in particular can be visually overwhelming without guidance on how to interpret them\.

---

## **Flexibility**

## 5\. Script Support

---

Kirrkirr uses **Unicode** internally and is able to import any Unicode text from XML files to the software\. There is no mention of a built\-in keyboard in Kirrkirr, so users will likely have to download a specific keyboard that matches their language to perform search functions in the software\.

## 6\. Language Support

---

Kirrkirr can support **multilingual dictionaries\.** The language reversal feature is available for bilingual dictionaries \(i\.e\., from a Ktunaxa\-English dictionary to an English\-Ktunaxa dictionary\)\.

## 7\. Customizability

---

There are **minimal customization** options in Kirrkirr as most of the processes are automated\.

Audio and images can be added to entries, and users can decide which games they would like to include in the dictionary\. Game options include crosswords and matching games\.

## 8\. Multi\-User Support

---

Kirrkirr **does not have any built\-in support for multiple users**, such as edit tracking, edit syncing, or file comparison\.

Kirrkirr does not appear to be designed to support multiple users collaborating on the same Kirrkirr project\.

---

## Data &amp; Compatibility

## 9\. Software Compatibility

---

Kirrkirr requires [Java](https://www.java.com/en/) to run and can work with any completed dictionary in XML format\.

## 10\. Import

---

KirrKirr can work with any XML dictionary file\. This means that it is compatible with data from any software that offers XML export\.

Note that KirrKirr is only compatible with completed lexicons, and the software is not designed to build a lexicon\.

## 11\. Export

---

The final product is a dictionary that can be **viewed exclusively in the Kirrkirr software**\.

There is no mention of how to export to other file formats or for external web posting\. A Kirrkirr file can be saved and shared with users who have installed Kirrkirr on their own device\.

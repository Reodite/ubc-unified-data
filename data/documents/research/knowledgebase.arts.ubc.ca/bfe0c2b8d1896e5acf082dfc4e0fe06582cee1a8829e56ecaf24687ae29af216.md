## Access

## **1\. Access &amp; Compatibility**

---

WOLF requires a software download and must be installed on a user’s computer\. The software can be downloaded through the [WOLF website](http://cs.sou.edu/~harveyd/wolf/index.php), [Microsoft store](https://www.microsoft.com/en-ca/p/word-oriented-linguistics-framework/9mxh374fskv5?cid=msft_web_chart#activetab=pivot:overviewtab), or [Apple store](https://apps.apple.com/us/app/wolf-dictionary-app/id1512504387?mt=12)\. The application is compatible with **Windows** \(64\-bit\), **macOS** \(64\-bit\), and **Linux** systems\.

## **2\. Cost**

---

The WOLF software is **free** to download\.

The software can only be used non\-commercially, which means that an organization cannot sell or install the WOLF application itself for a profit\. This applies only to the WOLF software, and not to dictionaries made with WOLF\.

## 3\. Internet

---

**An internet connection is required to download** the WOLF software, but once it is downloaded, **internet is not needed to operate** the software\.

## **4\. Skills Required**

---

WOLF is intended to be an easy\-to\-use interface with a similar feel to Microsoft Excel\. The software was designed for use by linguists, but can be used by community members as well\. The user\-interface does not offer much guidance when learning to use the software, so users new to WOLF should expect a learning period\.

---

## **Flexibility**

## **5\. Script Support**

---

WOLF can support multiple writing systems and is **fully Unicode compliant**\.

## **6\. Language Support**

---

WOLF can support up to **100 languages or dialects** in a single dictionary\. It supports **monolingual, bilingual,** **and multilingual** dictionaries\.

## **7\. Customizability**

---

The WOLF software has a **drag and drop mechanism** designed to easily attach **audio, video**, and **images** to words, definitions and examples\. There is no limit to the amount of definitions or examples that can be added to a single entry\.

The software has many style and formatting options to meet user needs as well as a template system that can be used\.

According to [Ransdell\-Green \(2021\)](http://hdl.handle.net/10125/74492), the Kala Language Project was able to collaborate with the developer of WOLF to add new features to the software to fit the needs of their project\. The research team added more style and formatting options which allowed for greater flexibility and customizations of fields, and included the addition of two new fields, morphemes and annotations\.

## **8\.** Multi\-User Support

---

**WOLF does not have any built in support for multiple users**, such as edit tracking and ways to compare or compile changes from different users\. Users can edit their own version of a dictionary database file and share it with other team members\.

---

## **Data &amp; Compatibility**

## **9\. Software Compatibility**

---

Import from **SIL programs** [WeSay](https://knowledgebase.arts.ubc.ca/wesay/), [FLEx](https://knowledgebase.arts.ubc.ca/fieldworks-language-explorer-flex/), and [Lexique Pro](https://knowledgebase.arts.ubc.ca/lexique-pro/) is supported\. See *[Import](https://knowledgebase.arts.ubc.ca/the-word-oriented-linguistic-framework-wolf-more-information/#wolf-import)* below for more information\.

## **10\. Import**

---

WOLF supports the importing of data from Microsoft Excel, MDF, and SDF\. New features of WOLF also support the SIL International’s LIFT format\. LIFT is an XML format for dictionaries\. LIFT allows movement of data between programs such as WeSay, FLEx, and Lexique Pro\. Using the LIFT format, users can import dictionaries into WOLF which have been created using another lexicography software\.

[Ransdell\-Green \(2021\)](http://hdl.handle.net/10125/74492) comments that previously data could only be imported via XML markup sheets that were specified with WOLF’s tagging system\. However, new features within WOLF that Randell\-Green and Dan Harvey developed now enable easy and direct import of spreadsheet data into WOLF without the need for XML markup\.

## **11\. Export**

---

WOLF is extensive and flexible in controlling dictionary output\. Users create one \(or a series\) of output templates, specifying which information fields they wish to export from their WOLF database\. Following the creation of an output template, users can use the WOLF dropdown menu to select the preferred output format\. To learn more about this feature visit this [page](http://cs.sou.edu/~harveyd/wolf/wolf_3/documentation/templates.html) of the WOLF website\.

The export file formats supported by WOLF are:

-   **RTF:** a popular way to export data since formatting is preserved\.
-   **PDF:** best used for hard copy printouts\.
-   **HTML:** WOLF offers one\-click generation of websites that can be integrated with user web content\.

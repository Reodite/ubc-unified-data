## Instructions/Manuals/Guides

[**1\. Installation Guide for Windows and Linux**](https://software.sil.org/downloads/r/dictionaryappbuilder/Dictionary-App-Builder-01-Installation-Instructions.pdf)

**Resource Type:** Downloadable Guide

SIL International\. “Dictionary App Builder: Installation Guide\.” *Digital App Builder Project\.* [https://software\.sil\.org/downloads/r/dictionaryappbuilder/Dictionary\-App\-Builder\-01\-Installation\-Instructions\.pdf](https://software.sil.org/downloads/r/dictionaryappbuilder/Dictionary-App-Builder-01-Installation-Instructions.pdf)\. Accessed May 25, 2022\.

---

This downloadable PDF guide covers the steps for installing DAB on Windows and Linux\. This guides outline which additional downloads are needed to create apps with DAB and walk users through each step of the download process\.

The guide is useful for users with Windows or Linux operating systems to review before choosing to download the software, as what can sometimes be a lengthy installation process are clearly outlined\.

The Installation Guide for Windows and Linux can be found [here](https://software.sil.org/downloads/r/dictionaryappbuilder/Dictionary-App-Builder-01-Installation-Instructions.pdf)\.

[**2\. Installation Guide for macOS**](https://software.sil.org/downloads/r/dictionaryappbuilder/Dictionary-App-Builder-03-Installing-and-Building-on-Mac.pdf)

**Resource Type:** Downloadable Guide

SIL International\. “Dictionary App Builder: Installing and Building Apps on a Mac\.” *Digital App Builder Project\.* [https://software\.sil\.org/downloads/r/dictionaryappbuilder/Dictionary\-App\-Builder\-03\-Installing\-and\-Building\-on\-Mac\.pdf](https://software.sil.org/downloads/r/dictionaryappbuilder/Dictionary-App-Builder-03-Installing-and-Building-on-Mac.pdf)\. Accessed May 25, 2022\.

---

This downloadable PDF guide covers the steps for installing DAB and building apps on macOS\. This guides outline which additional downloads are needed to create apps with DAB and walk users through each step of the download process\.

The guide is useful for users with macOS to review before choosing to download the software, as what can sometimes be a lengthy installation process are clearly outlined\.

This installation guide for macOS can be found [here](https://software.sil.org/downloads/r/dictionaryappbuilder/Dictionary-App-Builder-03-Installing-and-Building-on-Mac.pdf)\.

[**3\. App Building Guide**](https://software.sil.org/downloads/r/dictionaryappbuilder/Dictionary-App-Builder-02-Building-Apps.pdf)

**Resource Type:** Downloadable Guide

SIL International\. “Dictionary App Builder: App Building Guide\.” *Digital App Builder Project\.* [https://software\.sil\.org/downloads/r/dictionaryappbuilder/Dictionary\-App\-Builder\-02\-Building\-Apps\.pdf](https://software.sil.org/downloads/r/dictionaryappbuilder/Dictionary-App-Builder-02-Building-Apps.pdf)\. Accessed May 25, 2022\.

---

In this downloadable PDF guide, the process of building an app using the DAB software is explained\. The guide details how to prepare data to be moved into the software, create the app, and install the completed product on phones and tablets\. All of the tasks for creating an app are clearly outlined\.

This helpful guide walks users through each step to create an app using DAB\.

This app building guide can be found [here](https://software.sil.org/downloads/r/dictionaryappbuilder/Dictionary-App-Builder-02-Building-Apps.pdf)\.

[**4\. Distribution Guide**](https://software.sil.org/downloads/r/dictionaryappbuilder/Dictionary-App-Builder-04-Distributing-Apps.pdf)

**Resource Type:** Downloadable Guide

SIL International\. “Dictionary App Builder: Distribution Guide\.” *Digital App Builder Project\.* [https://software\.sil\.org/downloads/r/dictionaryappbuilder/Dictionary\-App\-Builder\-04\-Distributing\-Apps\.pdf](https://software.sil.org/downloads/r/dictionaryappbuilder/Dictionary-App-Builder-04-Distributing-Apps.pdf)\. Accessed May 25, 2022\.

---

This downloadable PDF guide details how to distribute an app once it is finished\. The document outlines the options for distribution for iOS and Android phones and highlights the benefits and drawbacks of each option\. The guide also covers how to distribute an app offline\.

This document is helpful for choosing which method of distribution best fit a specific project\.

This distribution guide can be found [here](https://software.sil.org/downloads/r/dictionaryappbuilder/Dictionary-App-Builder-04-Distributing-Apps.pdf)\.

## Access

## 1\. Access &amp; Compatibility

---

Pathway can be used on **Linux** or **Windows**\. It is not compatible with macOS\. To download the tool, users may visit the *[Download](https://software.sil.org/pathway/download/)* page of the Pathway website\.

[FLEx](https://dictionaries.sites.olt.ubc.ca/fieldworks-language-explorer-flex/) also must be downloaded for the Pathway plug\-in to run\.

## 2\. Cost

---

This is a **free** and **open\-source** tool\. However, SIL International encourages donations\.

## 3\. Internet

---

**Internet is required to download** the plug\-in for the first time\. Although it is possible to transfer a copy of Pathway offline using a USB drive or CD\-ROM following the instructions in [this document](https://software.sil.org/pathway/download/installing-offline/), this may be too complex for some users\.

Once downloaded the Pathway plug\-in can be used **offline**\.

## 4\. Skills Required

---

This technology is **largely automated and requires few computer skills**\. The interface uses simple click\-to\-select actions to execute commands\.

Pathway **requires existing lexicographic material** housed in FLEx, which requires intermediate computer skills\.

To make more complex changes to the appearance of the dictionary on Pathway, knowledge of [Cascading Style Sheets](https://cssreference.io/) is required\.

---

## **Flexibility**

## 5\. Script Support

---

**Pathway uses Unicode text** and Graphite font technology\.

All choices made in [FLEx](https://dictionaries.sites.olt.ubc.ca/fieldworks-language-explorer-flex/) regarding keyboard layout are automatically maintained in Pathway\.

## 6\. Language Support

---

The localized language version of Pathway will **maintain any language choices** made in FLEx\. For example, if a project was completed in French using FLEx, Pathway will adjust all of its commands and instructions to French as well\.

The final copy of the dictionary will be written in the selected language\.

## 7\. Customizability

---

Users can choose which fields they wish to include in the publication and select font styles when formatting\.

**More advanced users will be able to change properties of pages** such as spacing, headers, and embedded text by adjusting the Cascading Style Sheets\.

## 8\. Multi\-User Support

---

Pathway must be downloaded by each individual user on their own version of FLEx\. Pathway is designed to format export data from FLEx, and **does not have multi\-user support functions**\. The multi\-user functions of FLEx should be maintained when Pathway is installed\.

---

## Data &amp; Compatibility

## 9\. Software Compatibility

---

Pathway opens as a plug\-in within [FLEx](https://dictionaries.sites.olt.ubc.ca/fieldworks-language-explorer-flex/) and Paratext\. Data imported into Pathway must derive from one of these two software tools\.

Files exported from Pathway are compatible with other technologies which support the same files types\. See *[Export](https://knowledgebase.arts.ubc.ca/pathway-more-information/#pathway-export)* below for more information on available export file types\.

## 10\. Import

---

Data in Pathway must come from either FLEx or Paratext\. No other import options are available\.

## 11\. Export

---

**Pathway has four output formats for dictionary data:**

1.  **Word processor** outputs include ODT, DOCX, and PDF files\. These output types are useful for users who wish to print their dictionaries as is, or distribute them as digital files\.

2.  **Typeset** projects have two options\. The InDesign output generates an IDML file which can then be opened in InDesign \(for which the user must have a separate license\)\. The second Typeset output option is XeTeX \(SIL’s own typesetting software\) which generates a PDF file that can be typeset using XeTeX\. They note that XeTeX supports Graphite fonts and is able to render complex scripts\.

3.  **Smart Device** output is mainly Epub\. Epubs can be converted to Kindle and other e\-reader formats\. Epub files can be opened and read on smart phones and computers \(although an app which is able to open Epubs is often required\)\.

4.  **Website** output option of HTML5 is available\. This file type can be used to create a webpage that can be viewed on desktop computers, tablets, laptops and smart phones\.

There is a fifth type of output format for Mobile devices called GoBible, but the documentation states that this is intended to work primarily for scripture content\.

**Files from Pathway can be used as both digital and print resources\. Output files can also be sent to other software for further formatting\.**

Information on output file types can be found on the [Output Media](https://software.sil.org/pathway/features/output-media/) page on the Pathway website\.

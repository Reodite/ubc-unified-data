Under the *Documentation* menu tab on the WOLF website, users can find text\-based instructions and guides on how to use the WOLF software\. The WOLF documentation page includes guides that document WOLF features, information about customizing print layouts for dictionary output, dictionary creation details, drag and drop facilities, general operation, getting started with WOLF, importing XML worksheets, incorporating multimedia, phonetics, and searching and sorting\.

Users looking for specific guides to various WOLF features may find this resource helpful\.

The *Documentation* page can be accessed through the [WOLF website](http://cs.sou.edu/~harveyd/wolf/index.php)\. Hover the curser over the *Documentation* tab on the website menu\. ‘Wolf 3\.0\.3’ will appear in the drop down menu\. Click on Wolf 3\.0\.3 to load the page\.

**Kala Dictionary Making with the WOLF Lexicography Software:**  
**A Collaborative Effort**

This PDF presentation by Ransdell\-Green provides an overview of using WOLF for the community\-based Kala language project\. The sections provide details on the dictionary project and its software needs \(specifically the ability to support four dialects and two translation languages\), a general overview of WOLF, and how the research team were able to collaborate with the developer of WOLF to add new features to the software\. The new features added as a result of this collaboration include allowing the import of spreadsheet data into WOLF without the need for XML markup, adding more formatting and style options, and the ability for SIL’s LIFT format to work with the WOLF software\.

This presentation can be found [here](https://scholarspace.manoa.hawaii.edu/server/api/core/bitstreams/cfd75c53-608b-48ad-8c3b-206b7623058a/content)\.

Spanish – Navajo Dictionary on\-line in AULEX

## Language Name

Navajo\.

## Alternate Language Names

Navaho, Diné bizaad, Naabeehó bizaad\.

## Region

Arizona, Colorado, New Mexico, and Utah, United States\.

## Who

Manuel Rodríguez Villegas \(Compiler\)\.

## Tools and Framework used

This is an online dictionary\.

## Access

This dictionary is open access\.

## Included Languages and Directionality

Spanish to Navajo\. The search function operates in both directions\.

## Dialects Included

No dialect is specified for this dictionary\.

## Type of Dictionary

This is a bilingual, mono\-directional, online word list\.

## How are Entries Organised

Upon entering the site, users can only search words in either Spanish or Navajo\. Search results are listed alphabetically by Spanish\. Entries include the Spanish headword and the Navajo translation\. There is no other information included in the entries\.

Users can select *Download the complete vocabulary file here* \(or *Descarga el vocabulario completo aquí*\) below the search button on the opening page to download a \.txt file of the databank of Spanish to Navajo words\.

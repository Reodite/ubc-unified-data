## Instructions/Manuals/Guides

[**1\. Features Page**](https://software.sil.org/lexiquepro/features/)

**Resource Type:** Website

SIL International\. “Features\.” *Lexique Pro\.* [https://software\.sil\.org/lexiquepro/features/](https://software.sil.org/lexiquepro/features/)\. Accessed May 18, 2022\.

---

These click\-through webpages highlight all of the features of Lexique Pro, such as hyperlinks, dictionary indexes, images and audio, search function, semantic categories, and performing basic operations\.

These pages offer a helpful overview of features for users with easy internet access\.

This features page can be accessed [here](https://software.sil.org/lexiquepro/features/)\.

[**2\. User Guide**](https://software.sil.org/downloads/r/lexiquepro/Lexique%20Pro%20-%20User%20Guide%202.5.pdf)

**Resource Type:** Downloadable Guide

SIL International\. 2005\. “Lexique Pro \(Version 2\.5\): User Guide\.” [https://software\.sil\.org/downloads/r/lexiquepro/Lexique%20Pro%20\-%20User%20Guide%202\.5\.pdf](https://software.sil.org/downloads/r/lexiquepro/Lexique%20Pro%20-%20User%20Guide%202.5.pdf)\. Accessed May 18, 2022\.

---

This PDF user guide outlines the basic steps of configuring lexicographical data and distributing the output of Lexique Pro\. The guide is a helpful starting point for users new to the software who may not have a consistent internet connection, as it serves as an overview of basic functions\.

This document has not been updated since 2005 and there may be some discrepancies between what is explained in the user guide and what is shown in the newest version of the software\.

This user guide can be found [here](https://software.sil.org/downloads/r/lexiquepro/Lexique%20Pro%20-%20User%20Guide%202.5.pdf)\.

[**3\. FAQ Page**](https://software.sil.org/lexiquepro/support/faq)

**Resource Type:** Website

SIL International\. “Frequently Asked Questions\.” *Lexique Pro\.* [https://software\.sil\.org/lexiquepro/support/faq](https://software.sil.org/lexiquepro/support/faq)/\. Accessed May 18, 2022\.

---

This webpage offers answers to common questions that users may encounter\. Topics covered include details about paradigms and lexical function fields, how to use sound files, and how to add links\.

This webpage is most useful for those who have a specific issue that they encounter while working with Lexique Pro\.

This website can be accessed [here](https://software.sil.org/lexiquepro/support/faq)\.

## Reviews/Articles

[**4\. Holton \(2015\)**](https://vimeo.com/151191853?embedded=true&amp;source=vimeo_logo&amp;owner=25915524)

**Resource Type:** Video

Holton, G\. 2015\. “Making Dictionaries for Native Languages with Lexique Pro\.” *pre\-ATALM SHN Workshops*\. [https://sustainableheritagenetwork\.org/digital\-heritage/making\-dictionaries\-native\-languages\-lexique\-pro\-tutorial](https://sustainableheritagenetwork.org/digital-heritage/making-dictionaries-native-languages-lexique-pro-tutorial)\. Accessed May 16, 2023\.

---

**Making Dictionaries for Native Languages with Lexique Pro**

This video is a five minute, simple overview covering the strengths of the software\. It details the benefits of Lexique Pro for sharing and storing data, the use of semantic categories, and the benefits of adding links and additional files to a lexicographical tool\. The speaker details how to download and customize Lexique Pro to accommodate specificities of the input language\.

This video can be found [here](https://sustainableheritagenetwork.org/digital-heritage/making-dictionaries-native-languages-lexique-pro-tutorial)\.

[**5\. Guérin &amp; Lacrampe \(2007\)**](https://scholarspace.manoa.hawaii.edu/server/api/core/bitstreams/110004d4-5d02-4b1d-9ed4-dd26dc61d18f/content)

**Resource Type:** Academic Article

Guérin, V\. and Lacrampe, S\. 2007\. “Lexique Pro Technology Review\.” *Language Documentation &amp; Conservation,* 1\(2\)\. [https://scholarspace\.manoa\.hawaii\.edu/server/api/core/bitstreams/110004d4\-5d02\-4b1d\-9ed4\-dd26dc61d18f/content](https://scholarspace.manoa.hawaii.edu/server/api/core/bitstreams/110004d4-5d02-4b1d-9ed4-dd26dc61d18f/content)\.

**Lexique Pro Technology Review**

In this review, the authors discuss the process of setting up Lexique Pro, both when creating a lexicon from scratch and when using an existing database\. The authors discuss issues they encountered with the software and propose solutions to these issues for users\.

This article can be found [here](https://scholarspace.manoa.hawaii.edu/server/api/core/bitstreams/110004d4-5d02-4b1d-9ed4-dd26dc61d18f/content)\.

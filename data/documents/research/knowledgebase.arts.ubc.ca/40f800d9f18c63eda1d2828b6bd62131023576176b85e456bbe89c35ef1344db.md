## Instructions/Manuals/Guides

[**1\. Installation Instructions Forum**](https://community.software.sil.org/t/5-steps-to-get-started-with-flex-send-receive-with-language-forge/268)

**Resource Type:** Online Discussion Forum

chris\_hirt\. 2017\. “5 Steps to Get Started with FLEx Send/Receive with Language Forge\.” *SIL Language Software Community*\. [https://community\.software\.sil\.org/t/5\-steps\-to\-get\-started\-with\-flex\-send\-receive\-with\-language\-forge/268](https://community.software.sil.org/t/5-steps-to-get-started-with-flex-send-receive-with-language-forge/268)\. Accessed April 25, 2023\.

---

This online discussion forum offers a walkthrough with screenshots of how to get started on Language Forge, including creating a Language Forge account, connecting a project to [FLEx](https://knowledgebase.arts.ubc.ca/fieldworks-language-explorer-flex/) through Language Depot, adding new users, and assigning user roles\.

Since Language Forge connects with pre\-existing projects, this forum is adequate for users looking to connect their established FLEx projects with Language Forge\. Users looking to start a project from scratch would benefit from the SIL training course detailed on the [FLEx — Reviews &amp; Guides page](https://knowledgebase.arts.ubc.ca/fieldworks-language-explorer-flex-reviews-guides/) before attempting to start with Language Forge\.

This forum detailing installation instructions can be found [here](https://community.software.sil.org/t/5-steps-to-get-started-with-flex-send-receive-with-language-forge/268)\.

[**2\. Demo Video**](https://www.youtube.com/watch?v=zAVVC2Xlb0Q)

**Resource Type:** Video

Christopher Hirt\. 2021\. “LFv1 2021 Language Forge Demo\.” *YouTube\.* [https://www\.youtube\.com/watch?v\=zAVVC2Xlb0Q](https://www.youtube.com/watch?v=zAVVC2Xlb0Q)\. Accessed April 28, 2023\.

---

This YouTube video provides an overview of Language Forge, offering a detailed walkthrough of how to get started as a project manager\.

This is the most comprehensive guide to Language Forge available, and is a helpful place for Language Forge users already familiar with FLEx\.

This demo video can be found [here](https://www.youtube.com/watch?v=zAVVC2Xlb0Q)\.

[**3\. Community Discussion Forums**](https://community.software.sil.org/c/language-forge/20)

**Resource Type:** Online Discussion Forum

*SIL Language Software Community*\. [https://community\.software\.sil\.org/c/language\-forge/20](https://community.software.sil.org/c/language-forge/20)\. Accessed April 25, 2023\.

---

These community discussion forums include instructional posts and information about software updates from developers, and questions and feedback from Language Forge users\.

As of April 2023, there are no detailed guides for Language Forge\. However, the SIL Language Software Community is active, with both developers and other users of SIL software contributing\.

The community discussion forums can be found [here](https://community.software.sil.org/c/language-forge/20)\.

## Access

## 1\. Access &amp; Compatibility

---

Miromaa is **only available for Windows** operating systems, and users are recommended to install the software on Windows 10\. While lexicon compilation software is incompatible with Linux or MacOS, apps, final dictionaries, and wordlists are\.

Users must apply for a license to download and use the software\. More information about technical requirements can be found [here](https://www.miromaa.org.au/technical-requirements) \(Note: this page recommends using Windows 7 or 8, while other pages on the website recommend Windows 10\)\.

Miromaa offers a multi\-layered access system that can be used for the software and the final app or online dictionary\. Database sections can be password protected, and **users can be given varying access levels**, as follows: 

1.  ***Admin***—This title is for the first person who created a Miromaa account\. This individual can set up the database and control who else has access to the resource\. 
2.  ***Access All Areas***—This group has access to all areas of Miromaa, including editing the database and adding users\.
3.  ***Power User***—These users can access all the parts of setting up a dictionary\. They cannot add or change users\.
4.  ***Learner***—Users at this level can only access the learner pages on Miromaa\.
5.  ***Linguist***—Users in this category can access the entire application but cannot add or change users\. They are also shown links to pages with tools linguists may use\.
6.  ***Entry Only***—This group is designed for volunteers/workers entering data in a language project\. They can only access the entry screen and to\-do lists\.

There are built in fields to record which user has checked or verified each entry\. Users are also able to lock and restrict specific entires to prevent any further changes by other users once the entry is verified\.

## 2\. Cost

---

Depending on individual or organizational identity, Miromaa’s cost varies from **free to $550 \(AUD\) per license**\. To obtain a license, potential users must submit an application under one of the options listed on the [*Get Started*](https://www.miromaa.org.au/miromaa-software/get-started) page\. Every download of Miromaa requires a separate license, and multiple licenses are required even if one user intends to download Miromaa on multiple computers for their own use\. 

Free licenses may be available to users who are “Aboriginal, Torres Strait Islander, Indigenous, Native American, First Nations, Native person, or working with an Indigenous individual or group” \(Miromaa Software Website\)\. Users approved for a free license may have limited access to support directly from the Miromaa team\.

There are six separate applications for different levels and types of licenses\. The **three free licenses** are:

1.  Individual license
2.  Organization license
3.  Linguist license

The **three paid licences** all come with support from Miromaa and vary in cost based on how many licences are purchased\.

1.  1\-4 Licenses, costing $550 AUD per license
2.  5\-10 Licenses, costing $360 AUD per license
3.  11\+ Licenses, costing $275 AUD per license 

The Miromaa team encourages users, especially users from government or educational organizations, to pay for a license if possible\.

## 3\. Internet

---

It is not specified whether internet is required for all steps of making and accessing language resources on Miromaa, or which steps may be performed offline\.

## 4\. Skills Required

---

This software was designed to be **simple and easy to use for beginners**\. There are advanced fields available for users with extensive tech skills\.

The Miromaa website offers numerous resources that guide beginners through the process of using this language tool for the first time, as well as training, broader project planning, resource development, and technical help\.

## **Flexibility**

## 5\. Script Support

---

This software **can support multiple scripts** and can read non\-Roman fonts\. Support for Unicode is not specified\.

There is a built\-in special\-character keyboard, which will appear on screen in the software, and can support up to 30 customizable special characters\.

## 6\. Language Support

---

**Miromaa creates bilingual resources\.** The navigation of the website and the translations of words in the dictionary are automatically shown in English, but it is possible to change the translations in dictionaries and resources to another language by changing the field markers in a dictionary\.

## 7\. Customizability

---

The dictionary and wordlists are made with a template which users can customize by creating categories for their entries \(e\.g\. wildlife\), choosing the title page, adding multiple meanings for the same word, changing the dictionary fields, swapping the directionality of the dictionary \(i\.e\. English\-Indigenous language or Indigenous language\-English\), formatting the use of prefix and suffixes, and changing the order of the navigation icons\.

Levels of access can also be customized, as outlined above in the *[Access &amp; Compatibility](https://knowledgebase.arts.ubc.ca/miromaa-more-information/#miromaa-access-compatibility)* section\.

The Miromaa team can build mobile apps for users once data is entered into the software\. The app’s colours, opening screen image, app icon, acknowledgment, and credit pages can be customized\. Users can also add an “about your language” section which can be accessed by learners\.

Up to 30 special characters can be added to the built\-in on\-screen keyboard to make typing easier\.

## 8\. Multi\-User Support

---

Miromaa projects can have as many users as desired by the project admin\. User access levels vary as determined by project admin, as detailed above under *[Access &amp; Compatibility](https://knowledgebase.arts.ubc.ca/miromaa-more-information/#miromaa-access-compatibility)*\.

Each user must have an account\.

While the Miromaa software can be used offline, it requires internet access to facilitate automatic uploads so the rest of the language team has access to changes in the database\.

## Data &amp; Compatibility

## 9\. Software Compatibility

---

Miromaa is compatible with Excel, Audacity, [Lexique Pro](https://dictionaries.sites.olt.ubc.ca/lexique-pro/), [FLEx](https://knowledgebase.arts.ubc.ca/fieldworks-language-explorer-flex/), and [Toolbox](https://dictionaries.sites.olt.ubc.ca/toolbox/)\. More details can be found below in the sections on *[Import](https://knowledgebase.arts.ubc.ca/miromaa-more-information/#miromaa-import)* and *[Export](https://knowledgebase.arts.ubc.ca/miromaa-more-information/#miromaa-export)*\.

## 10\. Import

---

Miromaa can import language data from Lexique Pro, FLEx, and Toolbox, as well as audio from Audacity\.

Images and videos can be uploaded to Miromaa\.

Data can also be uploaded from an Excel file with the support of the Miromaa team\.

## 11\. Export

---

The final outputs of Miromaa are varied\. For the dictionary and wordlists, users can export language data as a PDF or a RTF that can be opened with Microsoft Word\. In Word, users can edit the style of the dictionary, and then either save it as a PDF to share electronically, print paper copies, or use other software to further format the data for publishing\.

An app created with Miromaa can be hosted on the Apple App Store by the Miromaa team and is accessible on iPhones or iPads\.

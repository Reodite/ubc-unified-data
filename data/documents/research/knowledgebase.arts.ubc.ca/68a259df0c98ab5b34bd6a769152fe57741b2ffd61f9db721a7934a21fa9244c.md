## Access

## 1\. Access &amp; Compatibility

---

FirstVoices is a **web\-based tool**\. It can be accessed on any browser\-based system \(e\.g\. Safari or Chrome\)\. This includes most mobile devices\.

To start a project, contact *hello@firstvoices\.com*\.

There are **three levels of access for language team members** on FirstVoices:

1.  **Recorders** can upload and edit entries but not publish them
2.  **Recorders with approval** can upload, edit and publish entries
3.  **Language Administrators** can upload, edit and publish entries, edit the language homepage, and add new team members

There are also **three levels of access for users** on FirstVoices archives and websites:

1.  **Public**: this includes anyone who visits the website without a login—these users are restricted to public content only on FirstVoices
2.  **General members:** this includes anyone who has created an account on FirstVoices—these users can be granted access to specific community sites, but generally have the same access as public users
3.  **Community members**: this includes users with an account who have been approved by a Language Administrator to view specific member’s content—these users can access all public content, as well as member’s only content for a specific language

## 2\. Cost

---

**FirstVoices is free for users and language teams**\. Language teams have free access to software, support, training, and documentation for First Nations communities in BC\.

## 3\. Internet

---

**Internet access is required** for language teams to contribute to a FirstVoices language website\. The website requires internet access and cannot be accessed offline\.

Once completed, the FirstVoices dictionary app can be downloaded and used online or offline\. FirstVoices keyboards can also be used offline once installed\.

## 4\. Skills Required

---

FirstVoices was designed with a community focus in mind and is intended to be accessible to users with limited background in computers\. It is **beginner\-friendly**\.

---

## **Flexibility**

## 5\. Script Support

---

This software can read non\-Roman fonts and **fully supports Unicode**\. FirstVoices offers downloadable keyboards which support special characters\. Currently, FirstVoices have developed keyboards for over 100 languages, including every First Nations language in Canada, Australia, and New Zealand, as well as many Indigenous languages spoken in the United States\.

If there is no keyboard that supports a specific language, the team is able to build one\.

## 6\. Language Support

---

FirstVoices creates bilingual dictionaries\. The website navigation and labels are all in English\. Language sites can be created with French instead of English\. Search queries work in both English/French and the target \(Indigenous\) language\.

There is an option to use the immersion mode when browsing a completed dictionary, in which the language interface is changed from English/French to the target language\. This does not happen automatically, and the language teams have to create a translated interface\.

## 7\. Customizability

---

Users can change the alphabet on FirstVoices to support their own orthography, create custom dictionary categories, customize the banner image and logo for the virtual dictionary, and edit their home page to include information about the language community, related links, news articles, and a greeting to users who access their website\.

Communities can also choose for the resource to be public or private\. 

## 8\. Multi\-User Support

---

FirstVoices is designed to be used by a language team, and therefore **has support for multiple users**\. FirstVoices is web\-based, and all changes are uploaded directly to the website, which can be seen by all members of the language team\.

View the *[Access &amp; Compatibility](https://knowledgebase.arts.ubc.ca/firstvoices-more-information/#access-compatibility)* section of this page for more information on the access levels which can be granted to different types of users\.

---

## Data &amp; Compatibility

## 9\. Software Compatibility

---

This software is self\-contained and is not compatible with other language tools\.

## 10\. Import

---

Data can be batch imported using a CSV file\. These files must be sent to the FirstVoices team in order for the data to be uploaded onto the website\.

Images, videos, and audio can also be imported\. Compatible file types are not specified\.

## 11\. Export

---

The final product of FirstVoices is a digital dictionary\. There are no built\-in options to export data from FirstVoices or to create print dictionary from the digital archive\.

All community language sites are hosted on the FirstVoices domain\.

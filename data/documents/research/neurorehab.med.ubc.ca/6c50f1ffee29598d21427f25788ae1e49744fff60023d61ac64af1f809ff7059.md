**GRASP** \(Graded Repetitive Arm Supplementary Program\) Home Version is an arm and hand exercise program that we developed for stroke patients with upper extremity impairments\. This version is meant to be used within the patient’s own home and is a homework\-based program\. The patient is responsible for doing exercises daily and should work with the therapist to determine which level to start at for each exercise\.

---

To get started with GRASP\-Home Version, please read through the [GRASP Terms and Conditions](https://neurorehab.med.ubc.ca/files/2013/06/GRASP-Terms-and-Conditions.pdf)\. If you choose to accept, you will be redirected to the GRASP\-Home Version resource downloads page\.

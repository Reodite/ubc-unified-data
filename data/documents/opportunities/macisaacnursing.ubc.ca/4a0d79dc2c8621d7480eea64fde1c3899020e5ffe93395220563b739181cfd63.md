## Mission to Launch: Introducing Workday Student 101

UBC’s renewed student information system \- Workday Student \- is set to be launched in phases starting in October 2023\. Foundational knowledge about the system is a great way to be prepared for future in\-depth training\.

Workday Student 101 will be delivered through webinars, blog posts, and web content to provide you with foundational knowledge before the launch\!

Attend the Community\-wide Virtual Workday Student 101 session to:

-   Receive high\-level, foundational knowledge about Workday Student
-   Understand the differences from our current SIS
-   Learn core concepts
-   Get an overview of how you will be trained

**Date: Wednesday, November 23, 2022**

**Time: 11:00am \- 12:30pm**

**[Register and learn more about Workday Student\!](https://irp.ubc.ca/community-events)**

    **Project Summary**
  
  - **Cell 2:**
  
    This project transforms FRST 232 into a ‘Zero\-Cost’ course by replacing expensive commercial manuals with an interactive, open\-access ‘mastery learning’ platform built in Quarto, an open\-source system for executable code  and interactive content\. In an era when Generative AI often encourages ‘blind code generation’, this initiative  addresses a critical pedagogical gap by shifting the focus to ‘AI\-Resilient’ debugging skills\.   
      
    The project is led by the Principal Applicant, who has a proven track record of creating successful OER materials  and won the 2023/24 OER Excellence and Impact Individual Award\. The project modernizes the Principal  Applicant’s Forest Computing open textbook by migrating it to this dynamic framework\. Unlike generic resources  using ‘toy’ datasets, we integrate authentic BC Ministry’s NFI \(National Forest Inventory\) data, such as timber  cruises and carbon budget models, to teach sector\-specific skills required by the natural resources workforce\.   
      
    A central feature is the ‘Guided Answer’ logic; instead of binary feedback, the system provides procedural hints that  force students to debug independently\. By eliminating approximately $880 in student costs annually and ensuring materials are WCAG 2\.1 screen\-reader friendly, this project guarantees equitable, high\-quality technical training for all students, preparing them for competitive co\-op placements and advanced research roles\.

  - **Cell 2:**
  
    This project focuses on developing an open educational resource focused on teaching data visualization  
    interactively online\. The goal of this resource is to improve the learning experience of UBC students \(and beyond\) in data visualization courses\. Proper knowledge of data visualization is a core component of data science and required for both effective exploration, communication, and consumption of insights derived from data\. Importantly, data visualization is also the main avenue of communication of data both in the private and public sector, and understanding how to interpret such visualizations is an integral part of being a data literate citizen, something we have all experienced the importance of during the COVID pandemic\. The proposed OER is a freely accessible online textbook that includes interactive exercises with immediate automatic feedback, so that learners can engage with the material effectively\. The OER will also contain short video explanation for relevant topics, and select data sets with high relevance for students and real world challenges\. All functionality of the OER will be available using a web browser, eliminating any needs to install or purchase anything; and plays nicely with accessibility tools built into browsers\.

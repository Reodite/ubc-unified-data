    **Project Summary**
  
  - **Cell 2:**
  
    This funding will support the development of a new new course for upper level undergraduates and graduate datasets of historical weather, and projections of future climate from the Coupled Model Intercomparison Project\)\. This course is being developed by an early\-career faculty member \(Lague\), and will be offered next \(2026\-2027\) year in Term 2 \(offered as GEOS\_V 504; anticipated enrollment \~20\)\. Lague is currently developing the course materials, and this rapid OER funding would allow the course to adopt many existing OER created by other climate scientists\. These materials require a modest amount of effort \(\~50 hours\) to set up on UBC high performance computing systems\. The materials consist of python “notebooks” \(interactive scripts\); while the bulk of the scientific code is directly translatable to this course, some modifications must be made to adapt the scripts to work on UBC computing systems\. The datasets involved in climate science are very large \(100s of GB to TB\) and require specific techniques, libraries, and analysis approaches on large memory, high performance computers \(HPC\) for analysis\. The course will focus on both the underlying physics of Earth system models, and on the practical analysis approaches used to deal with these challenging datasets\.  
      
    This Rapid OER funding is specifically targeted toward adapting existing OER material for the analysis component of the course\. The climate science community has many shared resources \(climate simulation data itself, as well as analysis scripts for such data\), but some level of proficiency in HPC systems, linux, python environment management, and programming is necessary to implement these shared, community\-built resources on a specific HPC system\. Past attempts at sharing these resources using Google CoLab and Amazon Web Services were successful for short periods of time, but inevitably ceased to function \(due to the pay\-to\-run nature of these platforms\), such that to actually use these resources in a class setting, a local \(university HPC\) analysis platform must be configured for the planned Earth system data analysis\.  
      
    This Rapid grant will fund a graduate student who is already proficient in HPC, linux, environment management, and python to adapt several of the community\-build analysis scripts to the UBC Sockeye system\. These resources will be used to teach the skills necessary to analyze and interpret Earth system data \(without also needing to teach each student to be an expert in HPC and Linux systems, which would prove a barrier to entry for many otherwise capable students given the limited time and scope of a single class\)\.

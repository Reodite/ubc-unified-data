| **Project Summary** | Approximately 2 years ago CPSC221 began the process of customizing an existing, and rather dated, open source textbook \(Open Data Structures, by Pat Morin\)\. Since then, our vision has migrated from a “textbook” to an “interactive learning resource,” available on the web and using the latest web technologies\. This OER rapid innovation grant will support Brendan \(applicant\) as he builds out the content of the text\. Interactive components include code illumination, algorithm visualizations, short programming exercises, etc\. The narrative of the resource will be consistent with the classroom instruction for the course, which is an introduction to algorithms and data structures with an emphasis on analysis and design\. |

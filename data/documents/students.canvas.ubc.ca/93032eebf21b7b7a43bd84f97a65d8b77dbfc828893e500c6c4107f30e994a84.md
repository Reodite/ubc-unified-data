## [Which browsers does Canvas support?](https://students.canvas.ubc.ca/which-browsers-does-canvas-support/)

By [Florence Kam](https://students.canvas.ubc.ca/author/florence-yin-to-kam/ "Posts by Florence Kam") on September 18, 2019

The most current version of a Canvas supported browser should be used\. In April 2019, Canvas announced that they would no longer support Internet Explorer\. This means that using Internet Explorer or any other unsupported browser may result in features that do not work as intended\. See a list of web browsers supported by Canvas\.
